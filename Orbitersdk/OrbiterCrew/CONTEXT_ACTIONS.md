# Контекстные действия человека (ТЗ для сессии «Экипаж», от «Транспорт», 2026-10-07)

Решение пользователя (2026-10-07): основной способ — **F-1 «метка и колесо»**, точный — **M-1 «режим курсора»**.
Оба работают по одному списку действий, который отдаёт машина/корабль. Отрисовка, ввод, досягаемость, время действий —
слой OrbiterCrew. Машины и корабли (МПУ, Э.МПУ, «Тантра», модули) только описывают свои узлы и выполняют действия.

## Поведение
- **F-1 (основной).** Узел в пределах руки, на который смотрит человек (луч из глаз), берётся в уголки-скобки; рядом
  короткий список его действий. Колесо мыши листает список, F выполняет выбранное. Недоступные пункты — серые, с причиной
  («нет кабеля», «нет крана», «машина не на тормозе»). Ничего не открывается поверх обзора.
- **M-1 (точный).** Alt (или средняя кнопка) — свободный курсор; узлы подсвечиваются под курсором (досягаемость та же,
  вытянутая рука); ЛКМ — меню у курсора. Для плотных мест: пульты, щитки разъёмов, модули с лючками. Совместимо с
  нынешним правилом «кнопки корабля жмутся курсором».
- **F-2** (без колеса: F открывает список, W/S выбор, F подтвердить, Esc закрыть) — запасной вариант, по желанию.
- **Колесо вне контекста не теряется** (требование пользователя): нет узла под взглядом или у узла одно действие —
  колесо делает то, что делало: масштаб/угол обзора от первого лица, дистанция камеры от третьего. Колесо листает
  действия только когда показан список из ≥2 пунктов. (Предложение: Shift+колесо — всегда обзор.)
- **Время.** У действия есть длительность: мгновенное (тормоз, ступени) или долгое (кабель — секунды, замена лотка
  батареи краном — минуты). Долгое идёт полосой у метки, человек в это время занят (не ходит), можно прервать (F/Esc
  или отойти). Машина получает итог: выполнено / прервано.
- **Условия честные**, их проверяет владелец узла (кран рядом, кабель дотягивается, машина на тормозе, есть заряженный
  лоток); OrbiterCrew проверяет досягаемость и состояние человека (в сознании, руки целы, не сидит/сидит — по узлу).
- **Оформление:** янтарные знаки на тёмном, моноширинный шрифт (в игре — ГОСТ тип А), уголки-скобки вокруг узла;
  без голограмм и «стекла» (стиль мостика: фотоника/ретро).

## Мышь (решение пользователя 2026-10-07)
- **Пешком:** постоянный обзор мышью (без зажатой ПКМ), курсора нет, точка прицела по центру — основа F-1.
- **Alt:** освобождает курсор (меню M-1, кнопки, верхняя панель и диалоги Orbiter, MFD); отпустил — снова обзор.
  Подсказкой явно показать, что меню Orbiter — через Alt/Esc.
- **В кресле у пульта** (мостик «Тантры», Э.МПУ): по умолчанию курсор (работа по кнопкам и экранам), обзор — по
  зажатой ПКМ, как сейчас.

## Интерфейс (предложение; имена и упаковку решает «Экипаж»)
Расширение `OcInteriorExt` (поля в конце, `size` как сейчас):
```
struct OcNode   { int size; int id; VECTOR3 pos; double reach; int inside; char label[64]; };
                  // pos: inside=1 — кадр интерьера; inside=0 — кадр корабля (снаружи). label в кодовой странице корабля
struct OcAction { int size; int id; char label[64]; int available; char reason[64]; double durationS; int interruptible; };
int  (*NodeCount)(void* ctx);
int  (*Node)(void* ctx, int i, OcNode* out);
int  (*Actions)(void* ctx, int nodeId, int personId, OcAction* out, int max);   // -> число действий; спрашивается при показе
int  (*Begin)(void* ctx, int nodeId, int actionId, int personId);               // 1 = началось (для мгновенных — сделано)
void (*End)(void* ctx, int nodeId, int actionId, int personId, int completed);   // долгое: выполнено (1) / прервано (0)
```
Старые `Count/Item/Use` остаются (входы, кресла, кнопки) — новые узлы их не заменяют, а дополняют.

## Предметы в руках (дополнение 2026-10-07, пользователь: «и предметы»)
Сейчас уже работает (TVehicles.dll, `Orbitersdk\samples\TVehicles\TVApi.h`): человек берёт у станции кабель или энергоячейку
(80 кг, 250 кВт·ч), несёт, подключает/вставляет в МПУ. Состояние «что в руках» держит реестр TVehicles, но в руках
ничего не видно и вес на человека не действует. Нужно от OrbiterCrew:
- `ocGive(personId, const OcHeld*)` → 1, если она может это поднять: сравнить **вес на этом теле** (масса × местное g / 9,81)
  с её `LiftCapacity()` (сервоприводы скафандра помогают), иначе 0 и подсказка «слишком тяжело» (на Земле ячейку 80 кг
  один человек без скафандра не поднимет — это честно; на Луне она весит как 13 кг).
- Предмет виден в руках (меш или коробка заданного размера, поза «несёт двумя руками»), его масса прибавляется к телу
  (инерция), ходьба замедляется по весу против `CarryCapacity()`, бег — нет при тяжёлом.
- `ocTake(personId)` — корабль/машина забирает предмет из рук (вставили ячейку, подключили кабель).
- `ocHeldOf(personId, OcHeld*)` — что у неё в руках.
- `OcHeld { int size; int kind; double massKg; double dims[3]; char mesh[64]; char label[64]; }` — kind: ячейка, вилка кабеля
  (её тянет кабель — масса малая, но ограничена длиной кабеля, это считает TVehicles), прочее.
TVehicles после этого перестанет держать своё «в руках» и будет спрашивать OrbiterCrew.

## Первые узлы МПУ / Э.МПУ (моя сторона, после готовности API)
- Разъём питания (бамперы): «кабель Тантры», «кабель модуля О», «отключить».
- Лотки батареи (2): «заменить (кран)» ~10 мин, «выдвинуть для осмотра».
- Сцепка (перед/корма): «опустить/поднять», «сцепить с <машина> <расстояние>», «расцепить».
- Ступени: «выдвинуть/убрать»; стояночный тормоз (с палубы/из кресла).
