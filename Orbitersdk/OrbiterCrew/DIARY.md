## 2026-10-01

- **Несколько членов экипажа.** Система рассчитана на любое число (каждый — свой конфиг: имя, масса, VO2max, голос, модель), но готова только Низа Крит. Второй человек — тот же конвейер (MPFB → комбинезон → export_skin → hand_shapes → face_shapes → текстура волос). Пока рано.
- **Радиационная карта** (отложена пользователем — «позже»): разрез поясов Ван Аллена через полюса до ~10 R⊕, цвет — доза за текущей защитой (комбинезон / скафандр / поле), её точка и орбита, отметки МКС и ГСО; для Луны и Марса — сводка (орбита / поверхность, часы до 100 и 500 мЗв). Мне — функция дозы в произвольной точке без привязки к персонажу; отрисовка на МФД — сессия «скафандр».
- **Не придумывать лишнего пока:** солнечные вспышки, выносливость на долгую дистанцию (гликоген, пот), пределы перегрузок — обсуждались, не начаты.
- **Грузы** — не реализуем пока.
- **Интеграция с кораблями** (шлюзы, посадка на борт, передача экипажа, сохранение) — главный следующий этап для сообщества.
- **Orbiter 2024:** основная платформа — 2016; сборка под 32-битный 2024 позже как бонус (вероятно, только пересборка под его SDK). 64 бита — не трогать.
- **Видеопрезентация альфы:** сцены — орбита у МКС (вращение), Луна (ходьба, ранец), Земля. Перед ней довести: стопы по рельефу и фиксация стопы в опоре, переходы стоп → шаг → бег → разворот, живая поза покоя (Neutral_ID уже скачан); у «скафандра» — провал ранца в грунт после посадки, звук ранца (могу сделать я), сценарии сцен.

## 2026-10-01 (позже)

- **Концепт пользователя у «Скафандра» (ещё собирается):** три контура управления скафандра без цифровой микроэлектроники (физический → аналоговый → оптический вычислитель) и иерархия ЖИЗНЬ → ВОЗВРАТ → ЗАДАЧА: верхний контур никогда не нужен для выживания. ## 2026-10-01 — посадка в корабль (рано, записано)

- **Посадка и высадка на любой корабль без его кода.** Человек при посадке не исчезает: убирается только его тело в мире, сам он живёт в реестре.
- **Почему у UMmu терялись люди:** экипаж хранился в сценарии корабля и записывался кодом корабля; корабль без поддержки UMmu его не писал. В SDK 2016 плагин не может сам писать в сценарий — пишут только корабли.
- **Наш обход:** невидимый служебный объект-«манифест» (наш лёгкий корабль без модели и столкновений), всегда вместе с кораблём-носителем. Orbiter сохраняет его в сценарий сам при любом сохранении, включая Ctrl+S: кто на борту, на каком месте, в каком состоянии.
  - Посадка: тело убирается, человек — в манифест. Высадка: у порта снова создаётся тело с тем же состоянием.
  - Погиб корабль — человек жив: манифест видит, что корабля нет, и выпускает людей в мир в точке гибели, в том, что на них надето.
  - Порты корабля — в нашем конфиге по имени класса корабля, по несколько строк на порт; без описания — место по умолчанию.
- **Сложность:** механизм один раз — несколько сотен строк; дальше каждый корабль — строки конфига. Тонкие места: пристыкованные корабли, переименование корабля, удаление корабля из сценария вручную.
- **Начать (когда придёт время):** посадка и высадка на Дельта-глайдер через конфиг.

## 2026-10-01 — травмы (принцип пользователя, рано)

- **«Экипаж» считает реальные травмы голого тела по физике:** удар по частям тела (голова, корпус, руки, ноги) → травма. `Exposure.impact` — по частям тела (скорость и направление).
- **Скафандр стоит между ударом и телом**, как и для всего остального: удар среды → скафандр (ослабил, перераспределил, может быть пробит) → до тела доходит остаток → травма.
- **Лёгкий скафандр «Каркас» — с компенсаторами нагрузки:** масса скафандра идёт по каркасу через стремена в грунт, не через тело. При ударе масса скафандра телу не добавляет — её энергию берут каркас и компенсаторы; тело подвешено в каркасе, компенсаторы гасят и часть удара самого тела. Шлем и оболочка защищают голову и корпус.
- **Скафандр «добавляет» только одно:** пробой оболочки → разгерметизация (`pIn` / `leak`).
- **По контурам:** гашение удара — уровень ЖИЗНЬ, физический контур (пассивные демпферы, без питания). Несение массы при ходьбе — активные приводы (аналоговый контур); без питания массу несёт человек (сейчас ×1,35 к расходу), но удар гасится пассивно.
- Числа защиты — после концепта трёх контуров («Скафандр»).

## 2026-10-01 — радиация: ждёт команды пользователя (не трогать)

Рекомендации «Смотрителя», к внедрению только по команде:
- Острая доза (лучевая болезнь) — в Гр-экв с ОБЭ, карьера — в Зв. Шкала: >1 Гр — лёгкая форма; 4–5 Гр — половина гибнет без лечения за недели; ~10 Гр — дни; >20–50 Гр — ЦНС, часы. Сейчас у нас смерть от 4,5–8 Зв за часы — слишком быстро.
- Один учёт дозы — только в организме человека; двигатель «Тантры» — источник в Среде, не отдельный учёт (у «Выхлопа» есть DoseLedger и шкала 5/50 Гр — свести к одной).
- Интерфейс с «Тантрой» (заметки «Выхлопа»: Orbitersdk/samples/Tantra/docs/PORTING_CREW.md): доза по компонентам { gamma, charged } в свободном пространстве; защита к каждому отдельно: гамма — ослабление по г/см² (корпус ×1,5, станция ×2, скафандр по своей толщине); e± сотен МэВ — свой закон, поле скафандра (fieldFactor 30) к ним не применять.
