# Индикация места на экране (ТЗ для сессии «Экипаж», от «Транспорт», 2026-10-07)

Решение пользователя (2026-10-07): индикация водителя Э.МПУ — **2D на экране, как HUD скафандра**, не на стекле в
кабине (стекло сделано, проверено в игре и отвергнуто: «мимо стекла, блекло и не то»).

Фокус всегда на человеке, поэтому на экран рисует только он (`CrewMember::clbkDrawHUD`). Машина на экран не рисует,
она только отдаёт данные. Отрисовку, место на экране и стиль задаёт «Экипаж», в стиле HUD скафандра: бирюзовые тонкие
линии, внизу строка «подпись над значением» («СКОРОСТЬ / 0,0 м/с»).

## Поведение
- Человек сидит в кресле корабля или машины, у кресла есть индикация (`SeatGauges` ≠ NULL и вернул > 0) — её строка
  или блок видны на экране **в любой одежде**: в комбинезоне тоже. Это HUD человека, не скафандра.
- В скафандре HUD скафандра не меняется. Как совместить два HUD, решает «Экипаж»: например, строка места заменяет
  нижнюю строку скафандра, пока человек сидит.
- Встал с кресла — индикация места пропадает.
- Опрос — каждый кадр или 10 раз в секунду, на усмотрение «Экипажа».

## Интерфейс (предложение; имена и упаковку решает «Экипаж»)
Расширение `OcInteriorExt` (поле в конце, `size` как сейчас):
```
struct OcGauge {
    int size;            // sizeof(OcGauge) as OrbiterCrew knows it: the ship writes no field beyond it
    char label[24];      // the caption, in the ship's code page: «СКОРОСТЬ»
    char value[24];      // the value with its unit, as shown: «12 км/ч»
    double frac;         // 0..1: a bar under the value (charge); < 0: no bar
    int state;           // 0 normal, 1 warning (amber), 2 alarm (red)
};
// The display of seatId for the person sitting in it, in the order shown. -> how many (at most max); 0 / NULL: none
int (*SeatGauges)(void* ctx, int seatId, int personId, OcGauge* out, int max);
```

## Что отдаёт Э.МПУ (кресло водителя; места пассажиров — ничего)
| подпись | значение | полоса | предупреждение |
|---|---|---|---|
| СКОРОСТЬ | 12 км/ч (назад: «Н 5 км/ч») | — | выше предела |
| ПРЕДЕЛ | 40 / 80 / 15 км/ч | — | — |
| ЗАРЯД | 78 % | заряд | < 30 % жёлтый, < 15 % красный |
| МОЩНОСТЬ | +120 кВт (на зарядке: «ЗАРЯДКА +250 кВт») | — | — |
| ЗАПАС ХОДА | 85 км (стоит: «—») | — | — |
| КАБИНА | 101 кПа 21 °C | — | вне нормы |
| КРЕН / ТАНГАЖ | +1° / +3° | — | крен > 15°, тангаж > 20° |
| ТОРМОЗ | стояночный / тормоз / — | — | стояночный — жёлтый |
| СЦЕПКА | ведёт EMPU-2 / за MPU-1 / — | — | — |

Пока поля нет, у Э.МПУ остаётся старая отладочная строка Orbiter внизу экрана, только в комбинезоне. В скафандре МПУ
уже показывает HUD скафандра через `mpuDriverState`.
