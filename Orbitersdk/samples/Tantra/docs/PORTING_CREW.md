# Радиация двигателя и экипаж (модуль OrbiterCrew, форк 2016)

UACS в проекте не используется. Экипаж — собственный модуль OrbiterCrew (сессия «Экипаж»).
Радиация анамезонного двигателя для людей подаётся туда как **источник в среде**: двигатель
сообщает мощность дозы в точке, а дозу копит организм человека (Person) с учётом корпуса и
скафандра. Учёт один — в «Экипаже».

## Что даёт ядро (`core/Radiation.*`, без зависимостей от Orbiter)

| Вызов | Что даёт |
|---|---|
| `Radiation::DoseRate(jetPower, r, inBeam)` | Гр/с для незащищённого человека на расстоянии r; `inBeam` — внутри конуса струи |
| `Radiation::LethalRadius / LethalBeamRange(jetPower, t)` | радиус смертельной дозы за время t |
| `Radiation::InterceptedPower / PlanetHazard / PlanetSafeLevel` | опасность для экосистем, снимаемая блокировка |
| `Radiation::PersonSafeLevel` | предел подачи, при котором никто вокруг не получает смертельную дозу за час |
| `DoseLedger` | накопление дозы по имени — только для чужих кораблей без OrbiterCrew |

## Модель вещества анамезона пересматривается

Числа ниже (62 % заряженных / 38 % изотропной гаммы, 0,41c, струя из пионов и мюонов, нагрев
кормы ~10¹⁹ Вт) относятся к **старой модели — аннигиляции антивещества**. По передаче
«Смотрителя», пользователь выбрал анамезон по Сапиге (направленная барионная струя «К-частиц»,
~0,79–0,93c, гамма мало); тема ведётся в сессии «Анамезон». Радиационную модель для людей нужно
пересобрать под неё. Требование к интерфейсу (доза в точке по компонентам) остаётся в силе.

## Поправки «Смотрителя» к старой модели (антивещество)

1. **Струя.** Пионы и мюоны — до ~3 км (βγcτ_μ при γ≈5). Дальше e± ~25 % заряженной мощности
   в конусе ~5° до ~10⁵ км (ларморовский радиус ~67 тыс. км в поле 5 нТл), за ним — рассеянная
   компонента ~P/(4πr²). «Смерть за 1 ч» в струе — ~2 млн км, а не 28 млн, как в нынешнем коде.
2. **Тень вперёд.** Конус ~5° по курсу заслонён самим кораблём.
3. **Корпус.** Гамма в сотни МэВ ослабляется в e раз на ~30 г/см²: корпус ×1,5, станция ×2
   (не 10–100).
4. **Шкала доз** одна, в Гр, — в модели организма «Экипажа».
5. **Интерфейс.** Нужна функция «мощность дозы в точке от “Тантры”» (DoseRateAt) для среды
   OrbiterCrew; конкретные вызовы согласовать с «Экипажем». Отдавать **по компонентам**
   `{ gamma, charged }` — мощность дозы в свободном пространстве, Гр/с: защита действует на них
   по-разному (гамма сотен МэВ — по г/см² корпуса и скафандра, ×1,5–2; против e± сотен МэВ
   противорадиационное поле скафандра почти бессильно, его ×30 к ним не применять).

## Открытый вопрос старой модели

Нагрев: изотропные гамма-кванты от реакции у кормы — около половины гамма-мощности (~10¹⁹ Вт)
попадает в сам корабль; ни выдержать, ни излучить такое нельзя. Варианты: канонное допущение о
защите камер; реакция далеко за кормой с магнитной передачей тяги; меньшая мощность.
