# Перенос радиационной модели в форк с UACS

В Orbiter 2010 экипажи — UMmu, а UMmu не даёт доступа к экипажу чужого корабля. Поэтому здесь
радиация только считается, копится и объявляется. В форке (Orbiter 2016 / OpenOrbiter, UACS) эти же
данные нужно отдать UACS, чтобы доза действовала на астронавтов.

## Что переносится без изменений

`core/Radiation.h/.cpp` не зависят от Orbiter и переносятся как есть:

| Вызов | Что даёт |
|---|---|
| `Radiation::DoseRate(jetPower, r, inBeam)` | Гр/с для незащищённого человека на расстоянии r; `inBeam` — внутри конуса струи |
| `Radiation::LethalRadius / LethalBeamRange(jetPower, t)` | радиус смертельной дозы за время t (гамма / по оси струи) |
| `Radiation::InterceptedPower(jetPower, R, d, beamOnPlanet)` | мощность, перехваченная планетой (верхняя атмосфера) |
| `Radiation::PlanetHazard(...)` | `None / Harm / Catastrophe` для экосистемы |
| `Radiation::PlanetSafeLevel / PersonSafeLevel(...)` | предельный уровень подачи для снимаемой блокировки |
| `DoseLedger` | накопленная доза по имени объекта (корабль, астронавт) |

Параметры — `ShipParams::MakeRadiationSpec()` (доля заряженных продуктов 0,62, полуугол струи 5°),
пороги — `RadiationSpec` (5 Гр — смертельная, горизонт опасной зоны 1 ч, вред экосистеме 10⁻⁴ и
катастрофа 10⁻² солнечного притока Земли).

## Что переписать в адаптере

`orbiter2010/TantraSafety.cpp` — образец. Он раз в 0,5 с:

1. Обходит планеты; обитаемая — если в атмосфере есть кислород (`ATMCONST::O2pp > 1000 Па`).
   Для каждой — расстояние, попадание в конус струи, перехваченная мощность, опасность.
2. Обходит корабли; для каждого — расстояние, в луче или нет, мощность дозы; копит дозу в `DoseLedger`
   (каждый шаг), объявляет пороги 1 Гр и смертельную.
3. Считает предел подачи (минимум по планетам и экипажам). Ctrl+J снимает блокировку, с постоянным
   предупреждением об опасности.

В форке меняется только шаг 2 — применение дозы:

* **Экипаж корабля с UACS.** Доза снаружи ослабляется корпусом: коэффициент защиты корабля нужно
  взять из его конфигурации или принять по умолчанию (для станции/корабля ~10–100). Дозу, делённую на
  защиту, добавлять каждому астронавту на борту через API UACS.
* **Астронавт в открытом космосе** (отдельный объект UACS) — доза без ослабления.
* **Смертельная доза** (≥ 5 Гр) — не мгновенная смерть: лучевая болезнь, смерть через дни-недели;
  ≥ ~50 Гр — поражение ЦНС, выход из строя за минуты-часы. Как это отразить, решает модель здоровья
  UACS; отдавать ей нужно накопленную дозу (Гр) и мощность дозы (Гр/с).
* **Собственный экипаж «Тантры»** камерами не облучается (защита камер и корабля в каноне);
  в модели доза своему экипажу не начисляется.

Точные вызовы UACS (получение списка астронавтов корабля, запись дозы / здоровья) уточнить по SDK
UACS при переносе — здесь они намеренно не выдуманы.

## Что ещё передать

* Сохранение `DoseLedger` в сценарий (сейчас не сохраняется: в 2010 это только сообщения).
* Экран дозиметрии: список объектов, доза, мощность дозы, в луче или нет.
