# Tantra and OrbiterCrew — Orbiter 2024 port (branch 2024)

This branch is the root of an Orbiter 2024 installation with only the project files tracked.

- `Orbitersdk/OrbiterCrew` — the crew system built for Orbiter 2024.
- `Meshes/Tantra`, `Textures/Tantra`, `Config/...`, `Scenarios/...`, `XRSound/Tantra` — ship and crew assets.
- The starship's sources are in branch `2016` (`Orbitersdk/samples/Tantra`); `build_2024.bat` and
  `install_2024.bat` there build and install the ship into Orbiter 2024.
