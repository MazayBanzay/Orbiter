«Тантра» — итоговый расчёт по всем формам

Одна модель для всех вариантов. Посадочная масса 2,9 кт (длиннее — +0,93 кт на каждую четвёрку ловушек), ЦМ s 53 (s от кормы). Корпуса — по сечениям макетов (C-147, Б, А «скат»), «Тандем» и «Триада» — Б со вставкой 24 / 48 м.

1. Скорость истечения по Сапиге

Сапига отвергает антивещество прямо: анамезон у него — метастабильные сверхтяжёлые ядра, которые в камере переводятся в нестабильное состояние и распадаются на поток лёгких частиц-барионов («К-частицы»). Скорость — «близкая к скорости света»; в его же численной оценке (тяга 10 МН при расходе 36 г/с) это ≈0,93 c. Продукты — заряженные барионы, гаммы по этой модели мало, значит доли «62 % заряженных» из пионной модели антивещества, заложенные сейчас в код (0,41 c), к анамезону Сапиги не относятся. Реальная поправка остаётся одна — коллимация магнитным соплом (~85 %): ≈0,79 c.

С реальной физикой это сходится так: разгон осколков до 0,93 c требует ~1,6 ГэВ на нуклон — больше массы самого нуклона. Энергия связи ядер даёт 8 МэВ, т. е. в 200 раз меньше. Значит, «метастабильное состояние» должно хранить энергию порядка массы покоя — это и есть единственная гипотеза Г1. Всё остальное — по опытным данным.

Главное, что показывает модель: корпус-несущее тело без крыльев статически неустойчив носом вперёд — его фокус на s ≈ 90, далеко впереди ЦМ (s 53): нос и плечо дают подъёмную силу впереди. Крылья в корме — это и есть хвостовое оперение, которое переносит нейтральную точку (НТ) назад. Поэтому боковые крылья обязательны — и по расчёту, а не только по облику. Запас устойчивости = (ЦМ − НТ) / длина: + устойчив, − нужен автомат.

5. Эскизы в плане

Красная линия — ЦМ посадочной массы, синяя пунктирная — нейтральная точка на дозвуке. ЦМ впереди НТ — устойчив. Оранжевый пунктир — второй шарнир.

6. Итог

Корпус. «Скат» (А) без настоящих крыльев неустойчив на 11–13 % длины — отпадает при требовании «крылья обязательно». C-147 и Б почти равны; Б остаётся. Удлинение вредит полёту: нос уходит вперёд, ЦМ посадочной массы — нет, и фокус корпуса убегает вперёд. «Тандем» устойчив только с крыльями K3, «Триада» — ни с одним складным вариантом.

Нынешние гребни K0 держат корабль ровно на грани (−0,8 %): летать можно только с автоматом устойчивости, а при любом сдвиге ЦМ назад (остаток зарядов, груз в корме) — нет. Кромка 2000 K — на пределе боразона.

Рекомендация — K★ «расчётный оптимум» для C-148. Получен перебором ~5000 геометрий при ограничениях: один шарнир (полуразмах ≤ 16 м), запас устойчивости ≥ 3 % и на малых углах, и на 15°, гиперзвук сбалансирован без рулей, кромка ≤ 1800 K, посадочная ≤ 165 м/с. Прошла одна геометрия: обрезанная дельта, корень s 0–38, конец s 0–10, задняя кромка — прямая по срезу кормы, стреловидность 60°, 768 м², 58 т. Запас +3,5 / +3,1 %, кромка 1685 K, K 3,4, посадочная 163 м/с. Задняя кромка на срезе кормы даёт максимальное плечо — поэтому крыло легче K2 при большем запасе. Элевоны — на задней кромке, они же дальше всего от ЦМ. K2 — запасной вариант (+32 т, запас вдвое меньше). Проверить в меше: корень s 0–38 по скуле проходит над нишами нижних кормовых ног (s 0–14) и над дверями кормовых гондол (s 30) — ниша сложенного крыла и эти люки делят один борт; по высоте сложенное крыло (16 м) занимает весь борт. Если нужен «Тандем» — только K3 с двойным сгибом (лишний шарнир, +80 т); складной K★ для него мал.

Для кода (после выбора): заменить плоскую пластину гребней на крыло по разделу 2 с фокусом s ≈ 24, вихревой подъёмной силой и сваливанием; скорость струи анамезона — 0,79 c (Сапига + сопло) вместо 0,41 c.
