# Шасси «Грань-Н2» (Т1Б-Н2) — тяжёлое трёхопорное

Предложение на решение пользователя (не принято). Расчёт: `scratchpad/gear/gear_calc.py` (сессия 2026-10-09), меш — `gen_lander.py`, группы `shassi_*`, `shassi_*_kolesa`, `stvorka_shassi_*`.
Оси: x вперёд, y вверх, z вправо, начало — ЦМ, метры.

## Решение
- Схема трёхопорная с передней опорой (ПО). Основные — тележки 2 оси × 2 колеса (тандем и спарка, как у тяжёлого фронтового бомбардировщика), ПО — спарка.
- Все 10 колёс одинаковые: Ø0,86 × 0,26 м, безвоздушные лепестковые (из МПУ). Лепестки — боразоновое волокно в борной керамике, обод и ступица — бериллиевая бронза с боразоновым покрытием.
- ПО x +6,75; основные x −3,4, z ±2,6. База 10,15 м, колея 5,2 м, ЦМ над грунтом 2,35 м. Доля веса: ПО 33 %, основные 67 % (почти равные три точки — для вертикальной посадки на грунт).
- Ниши — в корпусе, не в крыле: основные — вне баков (баки до |z| 1,875) и вне рядов чаш (до |z| 1,92), в зоне x −3,75…−0,75, |z| 2,05…3,15; люк (x ≥ 0,32, левый борт) не задет. ПО — впереди кабины, x 6,55…8,93 (до сопел ориентации у x 9,0).
- Уборка ВПЕРЁД, +90° вокруг оси z. Тележка основной в убранном виде стоит вертикально в глубокой нише борта (y −0,83…+1,03). Выпуск аварийно — весом, пружиной и набегающим потоком.
- Створки ниш заподлицо (повторяют днище и нижнюю фаску), петля по внешней кромке, в открытом виде висят вниз. Створки — бериллиевая бронза + боразон: закрытые они — аварийные полозья.

Почему лепестковые колёса годятся на 75 м/с: напряжение во вращающемся кольце ρv² не зависит от радиуса — 13 МПа для лепестков плотностью 2300 кг/м³ при прочности борной керамики с боразоновым волокном в сотни МПа. Нагрев от проскальзывания снят раскруткой колёс до касания.

## Отказы
| Отказ | Действие / резерв |
|---|---|
| Одна основная не вышла | Убрать все опоры и сесть на три закрытые створки-полоза (симметрично). Если чаши работают — сесть вертикально на чаши. Пробег на полозьях при μ 0,25 — около 1150 м |
| ПО не вышла | Посадка на основные, нос опускается на створку-полоз ПО на ~40 м/с |
| Отказ приводов уборки/выпуска | Второй привод (2 независимых электромеханических на стойку); затем свободный выпуск: вес + пружина + поток (уборка вперёд, поэтому поток помогает выпуску); замки с двумя пиропатронами |
| Пробой амортизатора или касание > 7 м/с | Сминаемый боразоновый сотовый картридж 0,35 м в стойке: до 10 м/с при 5,8 g |
| Срыв поля на малой высоте | Шасси выпущено всегда ниже 50 м; на Земле безопасно до 2,5 м — выше висение ограничено по времени и высоте |
| Повреждение колеса | Проколов нет; при потере 30 % лепестков колесо катится; на тележке 4 колеса — три несут |
| Отказ тормозного контура | Второй контур; элевоны как воздушный тормоз; обратный УВТ маршевых |
| Уклон > 10° или камень под опорой | Активная подвеска ±0,35 м; иначе висение и смена площадки |

## Проверка меша (gen_lander.py → lander_mesh.json, `gear.check`)
- Убрано: 0 вершин вне контура корпуса у всех трёх опор; всё в пределах контуров створок.
- Выпущено: колёса ниже корпуса, грунт y −2,35 у всех трёх опор; до плоскости открытой створки 0,17 (ПО) и 0,22 м (основные).

## Открытые вопросы
- Давление ПО на грунт Земли 0,96 МПа — для мягкого грунта много: вертикальная посадка на Земле — только на твёрдый грунт, либо ПО тоже сделать тележкой 2 × 2 (длиннее ниша, упирается в сопла ориентации у x 9).
- Не проработаны: подкосы/складывающиеся распорки и замки в меше, привод разворота ПО (управление на рулёжке), тепловой режим ниш на входе (створки закрыты, заподлицо — нагрев как у днища).
- Массу 2,8 т ещё нужно внести в таблицу масс спецификации — `lander_gran_v2.json` не трогал.


## Т1Б-А: пересчёт шасси на посадочную 85…99 т (2026-10-09, доведение варианта А)

Прежний раздел выше сохранён для истории (Н2, 49 т). Расчёт: `scratchpad/varA/patchA.py` + `final.py`; спецификация — `lander_gran_A.json` → `gear_A`. Меш не менялся — изменения в `mesh_changes`.

- Трёхопорная с ПО. Основные — тележки 2 оси × 2 колеса, ось поворота стойки x −3,60 (было −3,40), колея 5,2 м; ПО x +6,75 — спарка. База 10,35 м.
- Основные: 8 пневматических шин класса 44.5×16.0-21, 34 слоя, азот 2,34 МПа (Ø 1,14 м, ширина 0,41 м, 93 кг; 632 кН; 115,8 м/с макс., рейтинг 117,6 м/с). ПО: 2 шины 32×8.8, 20 слоёв, 2,07 МПа, рейтинг 250 миль/ч = 111,8 м/с (Ø 0,81 м — в прежней нише ПО). Безвоздушные лепестковые колёса для ВПП отклонены: Безвоздушные шины: данных о работе на скоростях порядка 100 м/с нет ни для одной конструкции (NASA Glenn Superelastic/Spring tire — луноходы/марсоходы; автомобильные NPT — проблемы на высоких скоростях, autoguide.com 2018) — для ВПП не принимаются. Лепестковые остаются только как вариант для внеземных грунтовых площадок при вертикальной посадке (малые скорости) — в эту массу не входят.
- Основные стойки: грунт ниже на 0,40 м (стойка +0,26 м, радиус колеса +0,14 м); высота ЦМ 2,75 м. Угол касания кормой (поворот вокруг задней оси тележки x −4,22, грунт y −2,75; по вершинам меша, щиток сдвинут на +0,24 м): щиток 0° — 21,7° (задняя кромка крыла/днища x −8,88); щиток 10° — 21,5°; щиток 15° — 18,9° (задняя кромка щитка). Было 16,2° (щиток 0°) — касание при α 18° было бы. Требование: α касания 18°, щиток ≤ 10° → запас 3,5°. Опрокидывание по Raymer: atan(2,75/1,708) = 58,2° ≤ 63°. Стояночный угол: нос вниз 2,35° (ПО не удлиняется — ниша упирается в сопла ориентации x 9,0), активная подвеска ±0,35 м выравнивает до 0,42°.
- Ниша основной: x −3,75…+0,15 (было до −0,75; удлинена вперёд на 0,90 м под тележку длиной 2,38 м — ось Ø1,14 + 0,10 зазор), |z| 2,05…3,15, глубина y −0,83…+1,03. Тележка в убранном виде складывается вдоль стойки. Конфликты: баки до |z| 1,875 и ряды чаш до |z| 1,92 — нет; люк (x ≥ 0,32, левый борт) — зазор 0,17 м; салон (оболочка до |z| 2,00) — зазор 0,05 м по z. Ниша ПО прежняя x 6,55…8,93 (шина 32×8.8 Ø0,81 ≤ прежних 0,86).
- 8 тормозов на колёсах основных, теплопоглотитель C/SiC. Тормозной теплопоглотитель C/SiC: предельная рабочая температура в воздухе 900 °C (C/SiC стабилен до 1350 °C, диски в неинертной среде ≤ 900 °C — патентный обзор, данные поиска 2026-10-09); удельная теплоёмкость ≥ 1,0 Дж/(г·°C) (US 11649191, «high heat capacity CMC aircraft brakes»: не менее 0,8, предпочтительно ≥ 1,0; при 1000 °C вдвое выше комнатной) — взята нижняя 1,0; плотность силицированного C/C 1,9–2,2 г/см³ (патент на силицированные углеродные тормоза). Расчётная энергия — полная кинетическая при посадке без тяги α 14° (без учёта аэродинамического сопротивления и реверса) — покрывает и штатную α 18°.
