2. Сечения по фактическому профилю и запасы по станциям

Кессон 0,15–0,65 хорды; верх — точки профиля меша (n3.sections, между станциями — интерполяция), низ плоский. Расчётные нагрузки = огибающая эксплуатационных × f 1,5 (АП-25.303). Допускаемое для ZrB₂–SiC: σ_изг 360 МПа при 1500 °C (Neuman 2013) / 1,25 (АП-25.621) = 288 МПа; хрупкий материал — критерий наибольшего главного напряжения (сдвиг сравнивается с тем же 288). Устойчивость панели между нервюрами (шаг 0,6 м) и стрингерами (шаг 0,3 м): σ_кр = 4π²E/[12(1−ν²)]·(t/b)², E 210 ГПа при 1500 °C (Тимошенко, Гере). Подбор: обшивка ≥ 8 мм (спецификация), стенки 6 мм, полки 30 см² × c/10,8 — увеличиваются только при MS < 0 (не потребовалось).

3. Термонапряжения по толщине

Верхняя оценка: весь падающий поток проходит через стенку стационарно, ΔT = q·t/k (k 56 Вт/(м·К), Zimmermann 2008); пластина с линейным перепадом, стеснённая от изгиба: σ = E·α·ΔT / [2(1−ν)] (Тимошенко, Гудьер; Roark, гл. 15), E 210 ГПа, α 5,0·10⁻⁶ 1/K (TPSX), ν 0,14. Перепад верх/низ кессона при свободном изгибе балки напряжений не даёт; стеснение в корне — не определено (нужна МКЭ).

4. Флаттер и дивергенция — оценка

  • Частоты консоли (Рэлей, E 210 ГПа при 1500 °C, G = E/2(1+ν)): изгиб 32,1 Гц, кручение 74,1 Гц, ω_θ/ω_h = 2,31. Изгибно-крутильный флаттер требует сближения частот; скорость флаттера — не определена (нужна нестационарная аэродинамика).
  • Панельный флаттер обшивки (Dowell, поршневая теория, λ = 2qa³/(βD), λ_кр ≈ 512): панель a 0,6 м, t 8 мм, q_max выхода 49,0 кПа, M 2 — λ = 1,34, запас ×383.

8. Балансировка

После облегчения гермокабины (−6,5 т у x +2,5) ЦМ ушёл назад: баллистика «всё в кормовом» x −2,59…−2,62 — устойчивой балансировки нет ни при каких элевонах (нужно x ≥ −2,52 при элевонах 0, ≥ −2,47 при −25°). Решение: перед баллистическим входом 4,85 т аргона входа перекачиваются в носовой бак (как для планирования) — x −2,09…−2,19; балансировка устойчива: элевоны 0 — α 46,0…53,8° (запас 2,2…2,3 % L), элевоны −25° — α 55,8…63,8°. Планирование (тот же ЦМ): щиток 15°, элевоны 0 — α 33,2…42,3°.

Д1. Шасси (пересчёт на 78,47…93,56 т)

Трёхопорная с ПО. Основные — тележки 2 оси × 2 колеса, ось поворота стойки x −3,60 (было −3,40), колея 5,2 м; ПО x +6,75 — спарка. База 10,35 м.

Основные: 8 пневматических шин класса 44.5×16.0-21, 34 слоя, азот 2,34 МПа (Ø 1,14 м, ширина 0,41 м, 93 кг; 632 кН; 115,8 м/с макс., рейтинг 117,6 м/с). ПО: 2 шины 32×8.8, 20 слоёв, 2,07 МПа, рейтинг 250 миль/ч = 111,8 м/с (Ø 0,81 м — в прежней нише ПО). Безвоздушные лепестковые колёса для ВПП отклонены: Безвоздушные шины: данных о работе на скоростях порядка 100 м/с нет ни для одной конструкции (NASA Glenn Superelastic/Spring tire — луноходы/марсоходы; автомобильные NPT — проблемы на высоких скоростях, autoguide.com 2018) — для ВПП не принимаются. Лепестковые остаются только как вариант для внеземных грунтовых площадок при вертикальной посадке (малые скорости) — в эту массу не входят.

Основные стойки: грунт ниже на 0,40 м (стойка +0,26 м, радиус колеса +0,14 м); высота ЦМ 2,75 м. Угол касания кормой (поворот вокруг задней оси тележки x −4,22, грунт y −2,75; по вершинам меша, щиток сдвинут на +0,24 м): щиток 0° — 21,7° (задняя кромка крыла/днища x −8,88); щиток 10° — 21,5°; щиток 15° — 18,9° (задняя кромка щитка). Было 16,2° (щиток 0°) — касание при α 18° было бы. Требование: α касания 18°, щиток ≤ 10° → запас 3,5°. Опрокидывание по Raymer: atan(2,75/1,708) = 58,2° ≤ 63°. Стояночный угол: нос вниз 2,35° (ПО не удлиняется — ниша упирается в сопла ориентации x 9,0), активная подвеска ±0,35 м выравнивает до 0,42°.

Д2. Гермокабина

Д3. Бак крыла

Недостача бака крыла закрыта заменой горячего барьера LI-2200 40 мм (ρ 352) на двухслойный микропористый той же теплозащиты: равное термосопротивление 0,040/0,0744 = 0,538 м²·К/Вт = 10 мм Microtherm-1200 (k 0,050, горячая сторона, класс 1200 °C) + 11,8 мм Microtherm Slatted-1000R (k 0,035, класс 1000 °C); всего 21,8 мм. При стационарном потоке на горячем слое 37 % перепада: при 1200 °C снаружи стык ≈ 690 °C < 1000 °C. Кессон вмещает больше без изменения формы.

  • Продлить бак в концевые части — отклонено: концевые части складываются на шарнире (0…90°), бак через шарнир не проходит, форма меняется.
  • Тоньше барьер той же теплозащиты — принято (Microtherm-1200 + Slatted-1000R, ρ ср. 301 кг/м³): ёмкость кессона 13,83 → 15,53 т, масса барьера 1,13 → 0,49 т.
  • Снизить потребность — облегчение гермокабины и пересчёт масс сами уменьшили аргон крыла: 16,47 → 15,00 т (max).

Д5. Криогеника аргона

Требуемая холодопроизводительность при 87 K: 46,5…57,3 кВт (приток × 1,25, MIL-STD-1540).

Вариант на борту: 15 × SPC-4 (≥ 4 кВт каждый при 87 K — верх семейства при 77 K, при 87 K больше) = 17,25 т, электрическая мощность ≈ 630 кВт (11 кВт на 1 кВт холода, ~25 % Карно; Карно при 87/300 K — COP 0,41), сброс тепла ≈ 687 кВт водой.

Принято: наземная установка (ангар/стартовая площадка) через заправочный разъём с подпиткой до отрыва, как у ВБ «Шаттла»; на борту — 0 т. Обоснование: приток 45,8 кВт есть только на земле (конвекция 300 K); в вакууме — только излучение. Заправка аргоном возможна лишь там, где есть наземное хозяйство, — там же и холод.

Stirling Cryogenics SPC-4 (паспорт DS-SPC-4, 2026): одноступенчатый криогенератор 2,5–11 кВт в диапазоне 50–160 K, масса 1150 кг, габарит 1,8×0,75×2,0 м, водяное охлаждение 5000 л/ч; семейство — 1–4 кВт при 77 K (буклет Stirling Cryogenics); SPC-1: ~1 кВт при 80 K при ~11 кВт электрической мощности (~25 % Карно; лекция ESS, indico.ess.eu/event/460, Lecture 10)

Д6. Балансировка после доведения

После облегчения гермокабины (−6,5 т у x +2,5) ЦМ ушёл назад: баллистика «всё в кормовом» x −2,59…−2,62 — устойчивой балансировки нет ни при каких элевонах (нужно x ≥ −2,52 при элевонах 0, ≥ −2,47 при −25°). Решение: перед баллистическим входом 4,85 т аргона входа перекачиваются в носовой бак (как для планирования) — x −2,09…−2,19; балансировка устойчива: элевоны 0 — α 46,0…53,8° (запас 2,2…2,3 % L), элевоны −25° — α 55,8…63,8°. Планирование (тот же ЦМ): щиток 15°, элевоны 0 — α 33,2…42,3°.

Режим «Вход — баллистика» в cg_modes — прежняя схема (всё в кормовом), для справки; штатная баллистика — с 4,85 т в носовом (ЦМ = планирование).

9. Открытые вопросы

  • Масса выросла: m₀ 108,24 (min) … 127,45 т (max) против 90,74 т Т1Б-Ф; основные причины — колпаки 9,85…19,98 т, гермокабина 0,23 т, шасси с f 1,5, тяги/чаши/маршевые от массы.
  • Т/В чаш на старте 1,34…1,34, при отказе одной 0,90…0,90 < 1 — отрыв на чашах с полным аргоном невозможен при отказе; штатно — разбег по полосе (сценарий 2).
  • Висение: ЦМ сухого −2,34…−2,41 м впереди центра рядов −2,50; перекачкой не достигается (нужно отрицательное количество в носовом) — передний ряд несёт на 0,0 % больше; ЦМ висения −2,50 м.
  • Ангар: стоя 19,800 м в проёме 20,0 (зазор 0,10 м с каждой стороны); в переходе (маршевые УВТ 10°) 20,095 м — проходить в ангар только в положении «стоянка».
  • Катушки: запас по критическому току не определён — проводник не задан (требование B_кр ≥ 18,6 Тл для аварийных 16 Тл).
  • Термонапряжение в кромках — верхняя оценка (стационарный проход полного потока); стеснение крыла в корне при перепаде верх/низ кессона — не определено (нужна МКЭ). Скорость классического флаттера крыла — не определена (нужна нестационарная аэродинамика); даны частоты.
  • Теневой экран 2,5 т (бюджет) против 8,05 т по площади — по-прежнему не пересчитан (решение пользователя).
  • Ядро Orbitersdk/samples/TantraLander не синхронизировано с Т1Б-А.
  • Посадка без тяги при α 14° — 103,2…112,7 м/с остаётся выше 95; штатно α 18° (91,2…99,6 м/с). Подзвуковая балансировка при α 18° с щитком ≤ 10° не считана (есть только гиперзвуковая сетка) — нужна дозвуковая аэродинамика.
  • Шина ПО 32×8.8: паспортная нагрузка не найдена (источник NASA даёт размер, слои, давление, скорость 250 миль/ч) — нагрузка ПО при вертикальной посадке 7 м/с не проверена по паспорту.
  • Прерванный взлёт (АП-25.735(f)): энергия зависит от скорости принятия решения на разбеге (сценарий 2) — в траектории не выделена; тормоза посчитаны на посадку α 14° без тяги.
  • Теплопоглотитель тормоза — по нижней удельной теплоёмкости из патентов (1,0 кДж/(кг·К)); паспорта конкретной марки C/SiC нет.
  • Двухслойный барьер Microtherm заменяет LI-2200 по стационарному термосопротивлению; переходный прогрев кессона на входе и температура горячей стороны (класс материала 1200 °C) не считаны.
  • Масса энергетики масштабирована линейно по ёмкости накопителя — реального аналога накопителя нет.
  • Меш не менялся: удлинение основных стоек, ось −3,60, ниша до x +0,15, новые шины — в mesh_changes (для генератора).
  • Баллистика с аргоном в носовом: балансировка α 46,0…53,8° (элевоны 0), не 90° — днище работает под углом; при отказе перекачки (всё в кормовом) устойчивой балансировки нет — нужен второй насос/клапан перекачки или балласт (не выбран). Планирование при новом ЦМ — α 33,2…42,3° (щиток 15°), выше прежних 19,5…24,3°: L/D ниже — дальность бокового манёвра не пересчитана.
