Крыло «Грани» Т1Б-А: силовая схема и запасы

Вариант А, массы max (взлёт 127,45 т, вход 99,36 т, посадка 93,56 т). Числа — из lander_wing.html и lander_gran_A.json (wing_calc, fittings, drives, norms); геометрия — реальный меш out/lander_mesh.json. Новый расчёт (навески) — раздел 5.

Вывод: кессон крыла несёт все девять случаев нагружения с запасом по нормам — минимальный запас MS 0,53 при f 1,5 × 1,25 (сдвиг стенок лонжеронов у корня z 3,0 м, баллистический вход n 5,5), но навеска концевой части при 0° по сдвигу не проходит (MS −0,08, если весь сдвиг идёт через неё), поэтому крыло целиком с запасом по нормам не доказано.
  • Навеска концевой части при 0° (выход из пике, n 2,5): сдвиг через стык 40,6 кН при подборе на 37,3 кН — MS −0,08, если весь сдвиг идёт через навеску. Замка и привода складывания в спецификации нет (момент 21,2 кН·м при 0°, 10,7 кН·м при 60°, экспл.).
  • Концевая часть 60° как киль при скольжении: расчётный угол скольжения не задан; навеска держит до β 11,4° (α 20°) … 17,3° (α 30°) при n 2,5.
  • Элевон: дозвуковая нагрузка (выход из пике) и нагрузка на q_max — не определены. Площадь в спецификации 6,75 м² против 3,10 м² по мешу.
  • Передача изгибающего момента корня 1444,9 кН·м в корпус: корневой узел подобран только на сдвиг.
  • Термонапряжения стеснения в корне — не определены (нужна МКЭ); термонапряжения кромок — только верхняя оценка (мин. MS 0,39).
  • Классический изгибно-крутильный флаттер — не определён (раздел 6).

1. Модель: меш и кессон

Корпус и левое крыло — призраком, правое крыло — с внутренним набором. Кессон 0,15–0,65 хорды, верх по профилю меша, низ плоский (y −0,9 м). Цвет отсека — наименьший MS (изгиб, сдвиг, устойчивость) на его корневой станции: к концу крыла запасы растут. Вращение — мышь или палец, наведение или касание — подпись элемента.

Станции: нагрузки выбранного случая и запасы

Q, M, T — эксплуатационные выбранного случая (знак «+» — изгиб вверх, T относительно 0,40 хорды). MS — огибающая всех случаев (расчётные нагрузки × 1,5, [σ] 288 МПа), как в lander_wing.html §2.

2. Случаи нагружения

Эксплуатационные нагрузки одного крыла, массы max. Гиперзвук — модифицированный Ньютон по мешу (давление на плоском днище постоянно, погонная нагрузка ∝ хорде; концевые части под углом δ — × cos δ), дозвук — распределение Шренка (NACA TM 948); разгрузка массой крыла, бака и аргона. Расчётные = эксплуатационные × f 1,5 (АП-25.303).

5. Навески: новый расчёт

Метод — тот же, что в lander_wing.html: давление на плоском днище из эпюры страницы, p = w/c (постоянно по размаху), модифицированный Ньютон для наклонённых поверхностей. Нагрузка = давление × площадь, момент = давление × ∫c·s·ds.

Исходные данные

  • Давление днища, эксплуатационное: планирование α 20/30°, n 2,5, m 99,36 т — p = 137,58/10,8 = 12,74 кПа; баллистика α 90°, n 5,5 — p = 307,47/10,8 = 28,47 кПа (эпюры wing_calc.max.cases).
  • Концевая часть: S_к = (3,18 + 1,40)/2 × 1,3 = 2,977 м² (geometry.wings; по мешу 2,947 м²); ∫c·s·ds = 1,684 м³ (плечо центра площади 0,566 м от оси).
  • Элевон: S_э = 3,095 м² по мешу (0,86 × 3,58 м). В спецификации (drives) — 6,75 м²: расхождение с мешем.
  • Подбор навесок (fittings): концевая часть — P_экспл 37,34 кН, элевон — 191,10 кН; коэффициент 6,67 × 1,15 к смятию, f 1,5.

Концевая часть

Подбор в спецификации (воспроизведён): P = n·m·g / S_пл · S_к = 2,5 · 99,36 · 9,807 / 194,2 · 2,977 = 37,3 кН — полное давление днища на концевую часть. 0°, выход из пике n 2,5 (Шренк): сдвиг через стык = Q(z 7,7) = 40,6 кН; M(7,7) = 21,2 кН·м; T = 17,3 кН·м MS = 37,3 / 40,6 − 1 = −0,08 Момент держит замок: плечо не больше полной высоты профиля h 0,200 м → пара сил ≥ 21,2 / 0,200 = 106 кН (экспл.) 60°, гиперзвук: sin θ = sin α·cos β·cos δ + sin β·sin δ; p_к = p·(sin θ / sin α)² β 0: Ньютон p·cos²δ = 3,18 кПа; страница для крыла берёт × cos δ = 6,37 кПа — принято (консервативнее) N = 6,37 · 2,977 = 19,0 кН → MS = 37,3 / 19,0 − 1 = 0,97; момент складывания 6,37 · 1,684 = 10,7 кН·м Скольжение: N = 37,3 кН при p_к = 12,54 кПа → β = 11,4° (α 20°), 17,3° (α 30°) 90°, баллистика: концевая часть ребром к потоку, аэродинамики нет; инерция 5,5 g — Q(7,7) = 10,8 кН → MS 2,47

Распределение сдвига между навеской и замком и по проушинам (кручение 17,3 кН·м) не определено — число проушин и место замка в спецификации не заданы. Если замок берёт часть сдвига, MS навески выше −0,08. Мера, если её примет пользователь: площадь смятия навески 3,47 → 3,77 см² (пропорционально 40,6/37,3).

Элевон

p_э = p·sin²(α + δ) / sin²α (δ «+» — задняя кромка вниз); при α 90°: p_э = p·cos²δ Баллистика α 90°, δ 0: 28,47 кПа · 3,095 = 88,1 кН → MS = 191,1 / 88,1 − 1 = 1,17 Баллистика α 90°, δ −25°: 23,38 кПа → 72,4 кН → MS 1,64 Планирование α 20°, δ +10°: 27,23 кПа → 84,3 кН → MS 1,27 Планирование α 30°, δ +10°: 21,05 кПа → 65,2 кН → MS 1,93 Планирование α 20°, δ +25° (упор): 54,45 кПа → 168,5 кН → MS 0,13 Шарнирный момент (плечо c/2 = 0,45 м, как в спецификации): 168,5 · 0,45 = 75,8 кН·м ≤ 86,0 → MS 0,13

δ ±10° — пределы балансировочной сетки (balance, final.glide), ±25° — упоры (anim.limits). Дозвук (выход из пике) и выход на q_max 49,0 кПа — не определено: распределение Шренка даёт только погонную нагрузку; нужна хордовая эпюра давления на отклонённом элевоне (дозвуковая и сверхзвуковая аэродинамика) и угол отклонения на q_max. Метод получения 191,1 кН в спецификации не записан и здесь не воспроизведён.

6. Флаттер, дивергенция, термонапряжения

Частоты консоли (lander_wing.html, Рэлей, E 210 ГПа при 1500 °C): изгиб 32,1 Гц, кручение 74,1 Гц, ω_θ/ω_h = 2,31.

Классический изгибно-крутильный флаттер — не определено. Рассмотрены признанные упрощённые методы:

  • NACA TN 4197 (Martin, 1958), параметр флаттера оперений ракет: построен для тонких оперений сплошного сечения (эффективный модуль сдвига сплошной пластины, (t/c)³). Полый керамический кессон с баком аргона вне его основы — не применён.
  • Типовое сечение (Theodorsen — Garrick; Bisplinghoff, Ashley, Halfman, «Aeroelasticity», 1955) с поршневой теорией (Ashley, Zartarian, 1956) для M ≥ 2: нужны ось жёсткости кессона, центр масс сечения с аргоном x_α, радиус инерции r_α и плотность воздуха в точке q_max (относительная масса μ). В источниках их нет.

Что нужно для расчёта: хордовое распределение масс (обшивка, кромки, бак, аргон), ось жёсткости, точка траектории q_max (высота, M); затем — поршневая теория и запас +15 % по эквивалентной скорости (АП-25.629).

Дивергенция (lander_wing.html, прямое крыло — верхняя граница опасности; стреловидность Λ 55° назад разгружает): q_div ≈ 8394 кПа ≫ q_max 49,0 кПа — ×171.

Панельный флаттер (Dowell, поршневая теория, λ = 2qa³/(βD), λ_кр ≈ 512): панель 0,6 м, 8 мм, q 49,0 кПа, M 2 — λ 1,34, ×383.

Термонапряжения (lander_wing.html §3, верхняя оценка: весь поток проходит через стенку, ΔT = q·t/k; σ = E·α·ΔT/[2(1−ν)]; × 1,5 против 288 МПа): нижняя обшивка MS 6,61; кромка у корня 1,17; кромка z 7,7 0,58; кромка концевой части 0,39. Стеснение кессона в корне при перепаде температур верх/низ — не определено: нужна МКЭ (оболочечная модель кессона с заделкой в корпус и полем температур входа).

7. Сечения по станциям (lander_wing.html §2, max)

Масса двух крыльев 4,85 т: обшивка 2,66, стенки 0,22, полки 0,41, стрингеры 0,28, трубы кромок 0,64; нервюры +15 %. Бак крыла: лейнер до z 6,88 (max), ёмкость кессона 15,53 т ≥ 15,00 т аргона (два крыла).
