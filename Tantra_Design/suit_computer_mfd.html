Компьютер скафандра — «Кромка визора», нижние МФД, Jura

Слева карта, справа цели и автопилот (сближение, синхронизация, стыковка, перелёт, посадка). Клавиши: 1–4 — режим, M / N — свернуть или развернуть левый / правый МФД (или клик по заголовку), [ и ] — страницы, T — следующая цель. Цвета — на странице «ОПЦИИ» левого МФД.

Откуда данные (всё есть в SDK Orbiter 2016)

  • Цели: список кораблей и дальности — oapiGetVesselCount / oapiGetVesselByIndex, GetRelativePos / GetRelativeVel; скорость сближения — проекция относительной скорости на линию визирования.
  • Сближение: LVLH-график (по ходу / к Земле) из относительного положения в орбитальной системе цели; ΔV синхронизации = |Vотн|; коридор скорости — правило «дальность / 100».
  • Стыковка: узлы цели — DockCount, GetDockHandle, GetDockParams (положение, ось, «верх») → смещения ΔX/ΔY и углы; для человека это шлюз или поручень.
  • Орбита: GetElements / GetApDist / GetPeDist; относительный наклон — по нормалям плоскостей.
  • Местная карта и профиль перелёта: рельеф из oapiSurfaceElevation по сетке вокруг (изолинии, крутые склоны), высота Солнца — для тепла.

В игре

  • Выбранный шрифт запекается в наш атлас букв (все четыре — SIL OFL, можно класть в аддон); к цветам атласа добавится оранжевый.
  • Оранжевый — всё, что делает автопилот, выбранная цель и предупреждения; красный — только опасность. Включённый автопилот — залитая кнопка, взведённый — рамка.
