# D3D11Client — свой графический клиент Orbiter 2024 на Direct3D 11

Написан по API Orbiter SDK (`GraphicsAPI.h`); код D3D9Client не используется (у него GPL/LGPL).
Orbiter 2024 32-битный, поэтому клиент собирается под x86.

- `build.bat` → `build\D3D11Client.dll`; `install.bat` → `Modules\Plugin\D3D11Client.dll` + шейдеры в `Modules\D3D11Client\`.
- Включение: Launchpad → Modules → снять D3D9Client, отметить D3D11Client → запуск через `Orbiter_ng.exe`.
- Самопроверка: каждые 10 с строка `D3D11Client: fps ... | GPU ms ...` в `Orbiter.log`, через 15 с снимок `Modules\D3D11Client\shots\start.png`.

## Этапы
1. Окно, устройство, камера (обратный Z, бесконечная дальняя плоскость — один буфер глубины от 0.1 м до планет), корабли: меши из шаблонов, материалы, текстуры, анимации (иерархия компонентов), видимость в кабине/снаружи, `oapiEditMeshGroup` / `oapiGetMeshGroup` (нужны CrewMember). — сделано
2. Планеты: дерево тайлов с уровня 4, текстуры и высоты из папок `Surf/Elev` и архивов `Archive/*.tree` (через `oapiInflate`), тайлы без своих данных берут текстуру и высоты предка, загрузка в отдельном потоке, отсечение по горизонту и по пирамиде видимости. — сделано
3. 2D: Sketchpad, поверхности, Blt, MFD, HUD, панели. — нет
4. Расширения для наших модулей (gcCore, AtmoFX-экспорты, `_heat`). — нет
5. Атмосфера, облака, звёзды, кольца, тени, эффекты из демо. — нет
