# D3D11Client — справочник разработчика

Собственный графический клиент Orbiter 2024 на Direct3D 11. Реализует `oapi::GraphicsClient` из
`Orbitersdk\include\GraphicsAPI.h`; написан по SDK, код D3D9Client не используется (у него GPL/LGPL).
Orbiter 2024 — 32-битный, поэтому клиент собирается под **x86**.

> **Состояние.** Все главы описывают код на 21.10.2026 и составлены по исходникам, без запуска клиента.
> Код продолжает меняться: номера строк в ссылках `файл:строка` могут сдвигаться — поиск по имени функции.

## Коротко

- **Файлы:** около 45 исходников в `src\` (список и назначение — [architecture.md §1](architecture.md)); `Client.cpp` —
  модуль, устройство, окно, поверхности, кадр; эффекты — в отдельных файлах по темам. `CloudLayer.cpp`, `EarthClouds.cpp`,
  `Cyclone.cpp` лежат в `src\`, но не собираются. Шейдеры — `shaders\*.hlsl`, компилируются при создании окна рендера
  с кэшем в `Modules\D3D11Client\shadercache\` ([shaders.md](shaders.md)).
- **Кадр:** тени (каскады) → атмосфера и небо → звёзды → планеты → корабли → AO, свет → жидкость → Солнце → атмосфера
  поверх сцены → облака и шторм → струи двигателей → частицы, дождь, капли на визоре → резолв MSAA / TAA → тон-маппинг,
  bloom, FXAA → 2D-панели; после `clbkRenderScene` — HUD модулей, слой экрана, `Present`. Точный порядок —
  [architecture.md §3](architecture.md).
- **Глубина:** обратный Z, бесконечная дальняя плоскость; один буфер D32F на всё от кабины до планет.
- **Координаты:** глобальная система Orbiter со сдвигом начала в камеру (всё в float относительно камеры);
  матрицы — строчные векторы (DirectXMath), `RotToXM` транспонирует матрицы Orbiter.
- **Потоки:** загрузчики тайлов (от 2 до 6; ресурсы создаются через free-threaded `ID3D11Device`), сторожевой поток
  `HangWatch`; контекст устройства — только в главном потоке.
- **Память:** процесс 32-битный (2 ГБ адресного пространства) — главный ограничитель; инструменты — строка
  `memory now`, `MemCensus`, `HeapTrack`, защита от кэша шейдеров драйвера ([architecture.md §6](architecture.md)).
- **Смена устройства:** между сценариями создаётся новое устройство; модули, хранящие объекты D3D, сверяют `g_devGen`.
- **Самопроверка:** строки `D3D11Client: …` в `Orbiter.log`, `crash.log` и `hang.log` в `Modules\D3D11Client\`,
  снимок `shots\start.png`; тестовый прогон — `tools\run_test.ps1` ([build-and-test.md](build-and-test.md)).

## Глоссарий

| Термин | Значение |
|---|---|
| `Surf` | реализация клиента для `SURFHANDLE` (текстура D3D11 + при необходимости DIB для GDI) — `Client.h` |
| `DevMesh` / `DGroup` | реализация клиента для `DEVMESHHANDLE` и её группы — `Client.h` |
| `VesselVis` | реализация клиента для `VISHANDLE` корабля — `Client.h` |
| `Planet` / `Tile` | планета и узел дерева тайлов — `Client.h` |
| `PStream` | реализация `oapi::ParticleStream` в клиенте — `Client.h` |
| `ExtState` (`g_ext`) | данные, переданные модулями через AtmoFX/gcCore — `Client.h` |
| `ClientCfg` (`g_cfg`) | настройки клиента (Advanced) — `Client.h` |
| слой экрана | DIB размером с окно, куда Orbiter и модули рисуют HUD/инфо-блоки через Sketchpad `NULL` — `Draw.cpp:316-382` |
| прокладка (shim) | `Modules\D3D11Client\D3D9Client.dll`, переадресующая экспорты в `D3D11Client.dll` — `shim\` |
