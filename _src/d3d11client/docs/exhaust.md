# Газодинамика струй двигателей: факелы, свечение, марево, дым и частицы

[← оглавление](DEVELOPER.md)

Состояние кода: 21.10.2026

Глава описывает, как клиент моделирует и рисует истечение из двигателей: объёмные факелы струй AtmoFX, свечение
горячих сопел, водородное пламя по равновесной химии, тепловое марево, конденсат и дым как трёхмерный поток, выброс
грунта из-под струи (GPU-частицы), собственные факелы кораблей (`VESSEL::AddExhaust`) и потоки частиц Orbiter
(`AddExhaustStream`). Номера строк сверены с файлами на дату выше; после правок искать по имени функции.

`AddExhaust` (§11), яркость которых делится на адаптацию.

**Глубина.** DSV не привязан; все проходы читают одновыборочную глубину сцены (`t5`, обратный Z) и сами решают
видимость: `ExSceneDist` (`exhaust_common.hlsli:12`) восстанавливает по `gInvVP` точку сцены за пикселем и её
расстояние (1e30 для неба). Марш луча обрывается на этом расстоянии, частицы гаснут «мягко» у поверхности.
Объёмные проходы (факел, свечение, поток) рисуют куб и оставляют только грани, обращённые от камеры
(`dot(n, wp) > 0`): каждый пиксель обрабатывается один раз, в том числе при камере внутри объёма.

**Смешивание.**

| Проход | Blend state | Формула |
|---|---|---|
| Свечение | `bsAdd` | `dst = src + dst`; альфа не меняется |
| Марево, смещения | `bsAdd` в `offRTV` | смещения суммируются |
| Марево, композиция | `bsOpaque` | пиксель сцены заменяется выборкой копии со смещением |
| Факел AtmoFX | `bsDual`: `ONE`, `SRC1_COLOR` | `dst = L + dst · T` (излучение + пропускание по каналам) |
| GPU-частицы, 3D-поток, факелы `AddExhaust` | `ONE`, `INV_SRC_ALPHA` | premultiplied alpha |
| Потоки частиц Orbiter | `bsAlpha` / `bsAdd`, с DSV (`dsRead`) | диффузные смешиваются, излучающие складываются |

## 3. Входные данные: откуда берутся струи

### 3.1. Экспорты AtmoFX (`Ext.cpp`)

| Экспорт | Что хранится | Где |
|---|---|---|
| `AtmoFX_SetJet(h, id, exitPos, jetDir, thrust, ve, exitT, ground, wet, rExit)` | `g_ext.jets[{h,id}]`: срез сопла и направление газа (система корабля), тяга [Н], скорость истечения [м/с], температура на срезе [K], класс грунта, влажность, радиус среза [м], время `t` | `Ext.cpp:91-96` |
| `AtmoFX_SetHeatSource(h, id, x, y, z, r, dT)` | `g_ext.heat[{h,id}]`: горячий узел (система корабля), радиус, превышение температуры; `dT ≤ 0` удаляет | `Ext.cpp:104-110` |

Струя участвует в кадре, если `thrust > 0` и обновлялась не более 0.5 с времени симуляции назад
(`Exhaust.cpp:297`). Записи с нулевой тягой из `g_ext.jets` не удаляются, а только пропускаются.
Известные вызывающие (на дату состояния): `Orbitersdk\OrbiterCrew\src\JetPack.cpp:833` — шесть камер «Модуля полёта»
(id 7200+i, `ve` = Isp, `exitT` 3000 K или 1800 K на форсаже, `rExit = 0.0405` м), `CrewMember.cpp:1419` — струя
под шагом (id 7300, `exitT` = температура воздуха; факел не рисуется, так как `T < 750 K`).

### 3.2. Универсальные струи кораблей без AtmoFX (`Exhaust.cpp:319-343`)

Если `Universal = 1` и `SmokeEnabled()`: для каждого корабля без струи AtmoFX, не дальше `3000 м + размер` от
камеры и в атмосфере с `GetAtmDensity() ≥ 1e-3`, каждый факел `GetExhaustSpec(i)` с `th`, `lpos`, `ldir`, без флага
`0x100`, у которого `GetThrusterLevel > 0.01` и `F = level · GetThrusterMax ≥ 10 Н`, становится струёй:

| Поле `ExJet` | Значение |
|---|---|
| `id` | `8000 + i` |
| `eg` | `lpos − ldir/|ldir| · lofs` (система корабля) |
| `dg` | `−ldir/|ldir|` |
| `thrust` | `level · GetThrusterMax(th)` [Н] |
| `ve` | `max(GetThrusterIsp(th), 500)` [м/с] |
| `T` | 3000 K |
| `rExit` | `max(0.6 · wsize, 0.03)` [м] |
| `yH2`, `h2` | 0.92, `true` (состав выхлопа «Модуля полёта»; задаётся после `JetGas`, `Exhaust.cpp:359`) |
| `universal` | `true` |

Универсальная струя не рисуется как факел (`DrawPlumes` пропускает), не выбрасывает грунт (не передаётся в
`GpuParticles::Update`) и даёт только источник 3D-потока (тепло, импульс, конденсат). Пламя корабля остаётся его
собственным факелом `AddExhaust` (§11).

### 3.3. Тестовые струи

`Cfg::Load` (`Exhaust.cpp:37-43`) читает `TestJet`/`TestHeat` только из файла, путь к которому задан переменной
окружения `D3D11CLIENT_EXHAUST_TEST`; из общего `Exhaust.cfg` они не читаются. Тестовые струи и узлы ставятся на
фокус-корабль с id от 9000 (`Exhaust.cpp:309-318`).

### 3.4. Перевод в глобальную систему (`Exhaust.cpp:345-376`)

Для каждой струи: срезы сопел запоминаются в системе корабля (`lastExitLocal`, до 8 на корабль) — по ним свечение
находит сопло после остановки струи; `Local2Global`/`GlobalRot` дают `eg`, `dg` в глобальной системе; `JetGas`
вычисляется по давлению и плотности атмосферы **у этого корабля** (`v->GetAtmPressure()`, `GetAtmDensity()`).
Горячий узел переводится в глобальную систему; `Tair` = температура атмосферы у корабля, 0 вне атмосферы
(тогда `dT` — собственная температура металла).

### 3.5. Газ у фокуса (`ExhaustFx::Scene`, `Exhaust.cpp:255-287`)

| Поле `ExScene` | Источник |
|---|---|
| `hBody`, `pp`, `Rp`, `R`, `GM` | `GetSurfaceRef()` фокуса, `G = 6.67430e-11` |
| `rhoG`, `pa`, `Tg` | `GetAtmDensity/Pressure/Temperature` фокуса; если есть `ATMCONST`, `Tg = pa / (rhoG · R)` при 2 < T < 3000 K |
| `Rgas` | `ATMCONST::R` |
| `mu` | Сазерленд для N2: `mu = 1.663e-5 · (T/273)^1.5 · 380 / (T + 107)` [Па·с], `T = Tg` или 94 K при `Tg ≤ 20` |
| `dense` | `rhoG > 1e-3` кг/м³ — включает сопротивление газа, марево, 3D-поток |
| `Rliq` | `R + liq.level`, если у планеты есть жидкость и `Liquids = 1` в `Client.cfg` |
| `titan` | имя тела `"Titan"` |
| `kE` | `π / Ω`, `Ω = π (R☉ / d)²`, `d = max(|Солнце − камера|, 2R☉)` (§4.4) |

Марево, 3D-поток, GPU-частицы и рамка факела используют газ **у фокуса**; газодинамика каждой струи — газ у её
корабля (`JetGas`, `H2Jet`). Для струй других кораблей на заметном удалении это даёт смешанные величины
(см. §16).

## 4. Физическая модель струи (`JetGas`)

`JetGas(ExJet& j, double pa, double rhoA)`, `Exhaust.cpp:108-136`. Все величины в СИ.

### 4.1. Состояние на срезе

| Величина | Формула | Переменная |
|---|---|---|
| показатель адиабаты | `γ = 1.3` (константа для всех струй) | `g`, `j.gamma` |
| входы с нижними границами | `ve = max(j.ve, 100)`, `Te = max(j.T, 300)`, `re = max(j.rExit, 0.005)` | |
| газовая постоянная выхлопа | `Rs = clamp(ve² (γ−1) / (2 γ Te), 8314/44, 8314/2)` [Дж/(кг·K)] | `j.Rs` |
| массовый расход | `ṁ = F / ve` [кг/с] | `j.mdot` |
| плотность на срезе | `ρe = ṁ / (ve π re²)` [кг/м³] | `j.rhoE` |
| давление на срезе | `pe = ρe Rs Te` [Па] | `j.pE` |
| число Маха на срезе | `Me = max(1.05, ve / sqrt(γ Rs Te))` | `j.Me` |
| степень нерасчётности | `n = pe / pa` при `pa > 1e-3` Па, иначе `1e12` | `j.n` |

Выражение для `Rs` следует из `ve² = 2γ/(γ−1) · Rs · Te`, то есть из предположения, что газ расширился от торможения
с температурой около `2·Te` (комментарий `Exhaust.cpp:113`). Пределы: от CO2 (M = 44) до H2 (M = 2).

Массовая доля свободного водорода (остальное — вода), `Exhaust.cpp:357`, из правила смешения
`1/M = yH2/2 + (1 − yH2)/18`:

```
yH2 = clamp((Rs/8314 − 1/18) / (0.5 − 1/18), 0, 1)
```

Струя считается водородной, если `H2Flame = 1` и `Rs > 450` (легче воды), либо если она универсальная
(`Exhaust.cpp:358-359`).

### 4.2. Режим в плотной атмосфере (нерасчётная струя)

| Величина | Формула | Переменная |
|---|---|---|
| радиус струи после выравнивания давления | `rj = re · clamp(n, 0.2, 30)^(1/(2γ))` | `j.rj` |
| длина ударной ячейки | `cell = 1.306 · 2 rj · sqrt(Me² − 1)` | `j.cell` |
| длина потенциального ядра | `Lc = 2 rj (4.2 + 1.1 Me²)` | `j.Lc` |
| отношение температур на прямом скачке | `t21 = (2γM² − (γ−1)) ((γ−1)M² + 2) / ((γ+1)² M²)`, `M = Me` | |
| амплитуда нагрева в «ромбах» | `shock = (t21 − 1) · 0.6 · min(1, |ln n|)` (ослабевает при `n → 1`: расчётная струя без скачков) | `j.shock` |
| вес вакуумного режима | `w = clamp((log10 n − 1.5)/1.5, 0, 1)`, `vacW = w² (3 − 2w)` | `j.vacW` |

`vacW = 0` при `n ≤ 10^1.5 ≈ 32`, `vacW = 1` при `n ≥ 1000`; между ними поля плотной атмосферы и вакуума
смешиваются линейно по `vacW` (§5.2).

Укорочение ядра лёгкой струи в тяжёлом газе (Thring & Newby 1953; Chen & Rodi; комментарий `Exhaust.cpp:129-131`):
при `rhoA > 1e-3` и `pa > 1e-3`

```
ρj = pa / (Rs Te),   Lc ← Lc · clamp(sqrt(ρj / ρa), 0.03, 1)
```

Для горячего водорода в азоте Титана множитель доходит до ~0.05: горячее ядро сантиметровое.

Предельный угол разворота потока в вакууме (Прандтль — Майер), `PrandtlMeyer` (`Exhaust.cpp:138-142`) и
`DrawPlumes` (`:628`):

```
ν(M) = a · atan(sqrt(M²−1)/a) − atan(sqrt(M²−1)),   a = sqrt((γ+1)/(γ−1))
θmax = clamp(π/2 · (a − 1) − ν(Me), 0.2, 2.3)   [рад]
```

### 4.3. Режим вакуума (источниковое течение)

Используется только в шейдере (§5.2): течение от точки на 0.5·re внутри среза (модель Саймонса), плотность

```
ρ(R, θ) = ρe · min(1, (re/R)²) · cos(π θ / (2 θmax))^(2/(γ−1))   при θ < θmax, иначе 0
T = max(Te · (ρ/ρe)^(γ−1), Ta)   (адиабатическое охлаждение)
```

### 4.4. Излучение, поглощение, единицы

- Поглощение тяжёлого (углеводородного) выхлопа: `κ = Kabs · ρ_выхлопа` [1/м], `Kabs` из `Exhaust.cfg` [м²/кг]
  (сажа, радикалы). Для водородной струи `Kabs = 0` (`Exhaust.cpp:640`): сажи нет, излучения Планка в видимом нет.
- Излучение в ЛТР: слой толщиной `ds` даёт `L += T_acc · (1 − e^(−κ ds)) · kE · B_rel(T)`.
- `B_rel(T)` — яркость чёрного тела относительно солнечной (5772 K) по каналам линейного sRGB, так что Солнце белое.
  Таблица `BlackbodyRGB` (`Exhaust.cpp:89-105`): Планк, свёрнутый с аппроксимацией CIE 1931 (Wyman, Sloan & Shirley
  2013) с шагом 2.5 нм на 380–780 нм, матрица XYZ → линейный sRGB; отрицательные каналы заменяются на `Y · 1e-4`.
  Текстура 256×1 `R32G32B32A32_FLOAT` хранит `ln(B_rgb(T)/B_rgb(☉))` для `T = 200 · 100^(i/255)` (200…20000 K),
  `Exhaust.cpp:215-227`. Выборка — `ExBlackbodyRel` (`exhaust_common.hlsli:33`), 0 при `T < 250 K`.
- `kE = π/Ω` (`Exhaust.cpp:281-285`): яркость относительно солнечной, умноженная на `kE`, — яркость в единицах
  клиента, где освещённость от Солнца равна 1.
- Пропускание воздуха между камерой и началом объёма: `ExAirTrans(dist) = exp(−FxExtinction(h_камеры) · dist)`,
  если FX-атмосфера активна (`exhaust_common.hlsli:56`); экстинкция берётся на высоте камеры для всего пути.

## 5. Объёмный факел (`exhaust_plume.hlsl`)

### 5.1. Коробка факела (`DrawPlumes`, `Exhaust.cpp:611-656`)

Струя рисуется, если `T ≥ Tvis = 750 K`, `thrust > 0`, не универсальная и не дальше 20 км от камеры. Одна
коробка (36 вершин, `Draw(36)`) на струю; константы перезаписываются `Map(DISCARD)` перед каждым draw.

Система факела: `ez = dg`, `ex = norm(ez × (0,1,0))` (или `× (1,0,0)` при `|ez.y| ≥ 0.9`), `ey = ez × ex`; начало
в срезе сопла. Коробка по `x, y` — `[−H, H]`, по `z` — `[z0, L]`.

| Величина | Формула |
|---|---|
| нижняя доля выхлопа, ещё горячая выше `Tvis` | `cmin = clamp((Tvis − Ta) / max(T(1 + shock) − Ta, 1), 0.02, 1)` |
| плотная атмосфера | `La = min(Lc / cmin, 60 Lc)`, `Ha = rj + 0.09 La` |
| вакуум | `Lv = clamp(re · (Tvis/T)^(−0.5/(γ−1)), 2re, 60re)` (из `(re/R)^(2(γ−1)) = Tvis/Te`); `Hv = Lv · (θmax > π/2 ? 1 : sin θmax)`; `z0v = θmax > π/2 ? −Lv · min(1, −cos θmax) : 0` |
| выбор | при `vacW < 0.999`: `L = La`, `H = Ha`; водород: `zg = 1.3 · max(flameZ, glowZ)`, `L = max(L, zg)`, `H = max(H, 2.2 (rj + 0.09 zg))`; при `vacW > 0.001`: `L = max(L, Lv)`, `H = max(H, Hv)`, `z0 = z0v` |
| плотность газа струи | `rhoJ = dense ? pa_фокуса / (Rs T) : ρe` |
| мерцание уровня | `flick = 1 + 0.04 · (hash(id, simt) − 0.5)` — ±2 % на кадр |

### 5.2. Поле газа (`Field`, `exhaust_plume.hlsl:82-151`)

Точка `q` в системе факела: `r = |q.xy|`, `z = q.z`.

**Плотная атмосфера** (`vacW < 0.999`, `z > 0`), наклон слоя смешения `pAir.y = 0.09` (≈ 5°):

```
rc   = rj · sat(1 − z/Lc)                          потенциальное ядро
b    = rj + 0.09 z                                 внешняя граница слоя смешения
cax  = z < Lc ? 1 : Lc/z                           доля выхлопа на оси
f    = r ≤ rc ? 1 : exp(−((r − rc)/(b − rc) · 1.4)²)
turb = ExFbm(...)                                  вихри, сносимые вниз со скоростью 0.5·ve
c    = cax · f · lerp(1, 0.55 + 0.9 turb, sat(1.5 z/Lc))
ph   = frac(z/cell),  w = rj (1 − |2ph − 1|)
dia  = sat(1 − r/w) · smoothstep(0, 0.15, ph)      «ромб» в каждой ударной ячейке
amp  = shock · exp(−z / (0.8 Lc))                  ослабление от ячейки к ячейке
Tj   = Te (1 + amp · dia)
Tair = Ta + (Tj − Ta) · sat(c)
ka   = Kabs · rhoJ · sat(c)
```

Диски Маха как отдельная структура не моделируются: ударные ячейки представлены только нагревом «ромбов» на оси.

**Вакуум** (`vacW > 0.001`): источниковое течение §4.3, `kv = Kabs · ρ`.

**Итог:** `κ = lerp(ka, kv, vacW) · flick`, `T = lerp(Tair, Tv, vacW)`.

**Водород** (`pH2.x > 0.5`): см. §6.4.

### 5.3. Марш луча (`PS`, `exhaust_plume.hlsl:155-208`)

1. Луч переводится в систему факела, пересекается с коробкой, обрезается глубиной сцены.
2. Отрезок дополнительно сужается до окрестности оси: ближайшая к оси точка луча `tc`, радиус охвата
   `reach = vacW > 0.5 ? H : 2.5 (rj + 0.09 z)` — тонкая струя, видимая поперёк, не проваливается между шагами.
3. `Steps` шагов (`|pZ.w|`), смещение шагов — interleaved gradient noise (Jimenez 2014); при TAA (`AntiAliasing = 5`)
   `pZ.w < 0`, и смещение меняется от кадра к кадру (`Exhaust.cpp:639`).
4. На каждом шаге: синий континуум `L += T_acc · kE · Kc · ⟨OH²⟩ · ds · flick²` (оптически тонкий), затем слой
   ЛТР `a = exp(−κ ds)`, `L += T_acc (1 − a) kE B_rel(T)`, `T_acc *= a`; выход при `T_acc < 1e-3`.
5. Выход: `SV_Target0 = L · ExAirTrans(ta)`, `SV_Target1 = T_acc` — dual-source blending (§2.2).

## 6. Водородная струя: химия, синий континуум, конденсат

### 6.1. Химическое равновесие (`H2Chem.cpp`)

- Виды: O, O2, H, H2, OH, H2O, N2; NASA 7-коэффициентные полиномы (GRI-Mech 3.0, `thermo30.dat`), ветви
  200–1000 K и 1000–3500 K (`H2Chem.cpp:12-27`); ниже 200 K `cp` держится на значении при 200 K (`H_RT`, `:32-38`).
- `Equil(b, T, p)` (`:49-109`): минимум энергии Гиббса методом элементных потенциалов, Ньютон по
  `(λ_H, λ_O, λ_N, ln N)` с частичным выбором главного элемента, шаг ограничен 2, до 400 итераций, сходимость
  `max|dx| < 1e-9`. `T` ограничивается 250…3500 K, `p ≥ 1` Па. Начальное приближение — потенциалы, дающие
  холодную смесь (вода, избыток H2 или O2, N2); комментарий указывает, что далёкий старт не сходится при низком давлении.
- `Cold(b)` (`:112-121`): ниже 1200 K диссоциации нет — вода, избыток H2 или O2, N2. `State` выбирает `Cold` при
  `T < 1200`, иначе `Equil`.
- Элементы выхлопа на кг: `H = 2 yH2/2.016 + 2(1−yH2)/18.015`, `O = (1−yH2)/18.015`; воздуха:
  `O = 2 yO2/31.998`, `N = 2(1−yO2)/28.013` (`ExhaustEl`, `AirEl`, `:131-132`).

### 6.2. Таблица смешения (`H2Chem::Mix`, `H2Chem.cpp:188-215`)

Струя смешивается с окружающим газом; `c` — массовая доля выхлопа в смеси.

```
fs  = yO2 > 0 ? 1 / (1 + 7.937 · yH2 / yO2) : 0     стехиометрическая доля (7.94 кг O2 на кг H2)
fsU = fs > 0 ? fs : 0.03                            масштаб таблицы
u_i = (i + 0.5)/32,  c_i = min(fsU · u_i / (1 − u_i), 1),  i = 0..31
h(c) = c · he + (1 − c) · ha + ½ ve² · c (1 − c)    энтальпия смеси, Pr = 1 (диссипированная кинетическая энергия)
```

`he` — энтальпия выхлопа в равновесии при `(Te, max(pa, 1e3))`, `ha` — воздуха при `max(Ta, 20)`. Температура смеси
находится бисекцией по `HMass(State(b, T, pa), T) = h` между `max(Ta, 30)` и 3500 K (до 36 шагов, точность 2 K);
при `T ≥ 1200` состав пересчитывается равновесием. В таблицу пишутся `T[i]` [K] и
`oh[i] = x_OH · pa / (kB T) · 1e-20` [1e20 м⁻³]. С кислородом свободный H2 сгорает около `c ≈ fs`: фронт пламени
(Бёрк — Шуман) получается из поля смешения; без кислорода (Титан, Марс) смесь только остывает.

Кислород окружающего газа (`H2Jet`, `Exhaust.cpp:386-396`): `yO2 = O2pp/p0 · 31.998 / M_газа` из `ATMCONST`
(`M = 8314.46 / R`); для `"Earth"` без `O2pp` — 0.232; при `pa < 1e-3` — 0.

Кэш: таблица (~1 мс на расчёт по комментарию) хранится на пару `(корабль, id)` и пересчитывается, если `yH2`, `Te`,
`ve`, `Ta` изменились более чем на 1 %, `pa` — более чем на 2 %, или изменился `yO2` (`Exhaust.cpp:397-405`).
Расчёт `Mix` вызывается с `pa ≥ 1` Па и `Ta ≥ 20` K.

### 6.3. Величины струи, выводимые из таблицы (`H2Jet`, `Exhaust.cpp:381-480`)

| Величина | Формула | Переменная |
|---|---|---|
| таблица OH | `ohMix[i] = pa > 1e-3 ? oh[i] : 0`; `tMix[i] = T[i]` | `j.ohMix`, `j.tMix` |
| дальность свечения по оси | первый `i`, где `oh[i] ≥ 0.1 · max(oh)` (т. е. `OH² ≥ 1 %` пика), `cMin = fsU · u_i/(1 − u_i)`; `glowZ = min(Lc / max(cMin, 1e-4), 200 Lc)` | `j.glowZ` |
| OH на срезе | `ohE = x_OH(yH2, Te, pe) · pe / (kB Te) · 1e-20` (замороженное течение в вакууме) | `j.ohE` |
| дальность пламени | `flameZ = Lc / (0.3 fs)` при `fs > 0` и `pa > 1e-3`, иначе 0 | `j.flameZ` |

### 6.4. Свечение в шейдере (синий континуум)

Модель (`H2Chem.h:116-118`): видимый свет безсажевого пламени H2 — «синий континуум» 220–600 нм с плоским
максимумом около 440 нм (Fiala 2015), излучательная способность `∝ [OH]²`, абсолютная величина
1.53e-21 см³/(молекула·с·нм) при 375 нм и 3000 K (Vanpee & Mainiero 1979).

`Cont(λ)` (`H2Chem.cpp:148-154`) [Вт/(м²·ср·нм) на `[OH]²` в м⁻⁶ на метр пути]:

```
S(λ) = exp(−((λ − 440)/120)⁴)
k(λ) = 1.53e-21 · 1e-6 · S(λ)/S(375)     [м³/с/нм]
Cont(λ) = k(λ) · h c / λ / (4π)
```

`ContinuumRGB(K)` (`:217-227`): `K[ch] = Σλ rgb(Cont) / Σλ rgb(Planck(5772 K)) · 1e40` — на единицу
`(1e20 м⁻³)² · м`, относительно Солнца, как `B_rel`. `ContinuumLuminance()` (`:229-234`):
`683 · Σ Y(λ) Cont(λ) · 2.5 · 1e40` [кд/м² на `(1e20 м⁻³)² · м`] — только для журнала.

В `Field` (`exhaust_plume.hlsl:111-133`) при `pH2.x > 0.5`:

1. Скорость на оси `uc = 2 · pAir.w · min(1, Lc/zc) = ve · c_ax`, частота прохождения крупных вихрей
   `fe = 0.6 uc / b` [Гц].
2. Доля, разрешаемая выдержкой кадра `dt_exp = pH2.z = clamp(1/fps, 1/240, 0.1)` с:
   `vis = max(1/(1 + fe · dt_exp), lerp(0.3, 1, far))`, где `far` растёт к концу свечения и к краю струи.
   Фаза вихрей: `phE = gShT · min(fe, 0.45/dt_exp)` — не быстрее, чем кадры способны показать; `gShT` — момент
   внутри выдержки, распределённый по пикселям.
3. Крупные вихри смещают точку (`wv`, 2 октавы шума × `vis`), доля `cw` пересчитывается в смещённой точке по той же
   модели ядра и слоя смешения.
4. Пульсации доли: `I = min(0.22 (1 + 3η²), 1.5) · sqrt(1 − 0.6 vis²) · sat(zw/rj)`, `η = rw/bw` (rms 0.22 на оси,
   Panchapakesan & Lumley 1993).
5. `⟨OH²⟩ = OH2Pdf(cw, I)` (`:68-78`): среднее `OH²(c)` по гауссовой плотности `c` вокруг `cw` с σ = `c · I`,
   6-точечная квадратура Гаусса — Эрмита, `c` обрезается в 0…1. `OHMix(c)` (`:53-60`) — линейная интерполяция
   таблицы по `u = c/(c + fs)`. Множитель `(1 − vacW)`.
6. Вакуумная часть: `oh2 += (ohE · ρ/ρe)² · vacW` — OH среза, переносимый замороженным течением.

Свет в PS: `L += T_acc · kE · Kc · ⟨OH²⟩ · ds · flick²`. Поглощения нет (`Kabs = 0`), поэтому водородная струя
сама по себе не затемняет фон.

### 6.5. Конденсация воды (Шмидт — Аппельман)

Условия расчёта (`Exhaust.cpp:419`): `Particles = 1`, `pa ≥ 1` Па, `ρa ≥ 1e-4`, `vacW ≤ 0.5`.

```
burn = yO2 > 0 ? 1 : 0
W  = (1 − yH2) + burn · 8.937 · yH2                         кг воды на кг выхлопа (с догоранием)
Q  = ExhaustHeat(yH2, Te, pa, Ta) + ½ ve² + burn · 1.2e8 · yH2   Дж на кг выхлопа
cp = Rg γa/(γa − 1),   Ma = 8314.46/Rg                      газ из ATMCONST (по умолчанию R = 287, γ = 1.4)
ea = (тело "Earth") ? Humidity · EsLiquid(Ta) : 0           остальные тела сухие
```

`ExhaustHeat` (`H2Chem.cpp:176-180`) — теплота охлаждения кг выхлопа от равновесия при `(Te, max(p, 1e3))` до
холодной смеси при `Ta`. `Condense(W, Q, pa, Ta, cp, Ma, ea, cStar)` (`H2Chem.cpp:236-253`): линия смешения по
64 точкам `c` логарифмически от 1e-8 до `cMax = min(0.1, 200 cp/Q)`:

```
T(c)  = Ta + c Q / cp
e(c)  = ea + c W (Ma/18.015) pa                 разбавленная смесь
es    = EsLiquid(T)                             сначала капли (насыщение над водой; ниже 123 K — над льдом)
fc(c) = e > es ? (e − es)/e : 0
```

Возвращается `max fc` (доля воды выше насыщения), `cStar` — наибольшее `c`, где `fc ≥ 0.5 · max`. Давление
насыщения: над водой — Murphy & Koop 2005 (`EsLiquid`, `:168-174`, до 373 K), над льдом — `EsIce` (`:163-167`).

След видим, если `fc ≥ CondMin` и `cStar > 0`. Далее (`Exhaust.cpp:437-479`):

| Величина | Формула |
|---|---|
| эффективный диаметр | `dEff = 2 rj · sqrt(clamp(ρj/ρa, 1e-6, 1))`, `ρj = pa/(Rs Te)` |
| где средняя смесь достигает `cStar` (Ricou & Spalding 1961) | `zStar = vis ? clamp((1/cStar − 1) · dEff / 0.32, 4 re, 60) : 1` [м] |
| высота среза над поверхностью | `alt = GetAltitude(ALTMODE_GROUND)`, при жидкости `min(alt, |r| − Rliq)`, плюс проекция `eL` на вертикаль |
| путь до поверхности | `down = −dL·up`; `zHit = (alt − 0.15)/down` при `down > 0.2` и `alt > 0`, иначе 1e9 |
| время жизни видимой массы | `Ta < 160 K` → 40 с; `ea ≥ EsIce(Ta)` → 20 с; иначе 3 с |
| конденсат | `condZ = min(zStar, zHit)`, видимая масса `fc · W · ṁ` [кг/с] |

Доля конденсата вдоль струи растёт как `(z/z*)²` (поток массы гауссова профиля за порогом `c*`).

Дальше конденсат идёт либо в 3D-поток (`Smoke = 1`, §9), либо в GPU-частицы как источник вида 4 (§10.3).

## 7. Свечение горячего металла (`exhaust_glow.hlsl`)

В текущем `Exhaust.cfg` выключено (`Glow = 0`): узлы AtmoFX управляют только маревом, модуль показывает свечение
сам (материал с эмиссией).

CPU (`DrawGlow`, `Exhaust.cpp:497-533`):

- узел с `T = Tair + dT < 650 K` пропускается (комментарий: B(650 K) в видимом ~1e-12 солнечной);
- узел связывается с соплом: струя того же корабля, у которой `|eg − узел| < 3r + rExit`; если струи в кадре нет —
  срезы, запомненные в `lastExit`. Узел без сопла не светится (`Exhaust.cpp:516`);
- центр — срез сопла, радиус — `rExit`, ось — направление газа; не дальше 5000 м; до 32 узлов;
- инстансированный draw: `DrawInstanced(36, n)`, коробка `3.5 r` вокруг среза.

PS (`exhaust_glow.hlsl:34-67`): нормаль поверхности из производных восстановленной позиции (до `discard`);
`z = −dot(sp − c, ax)` — глубина внутрь сопла от плоскости среза, `r` — расстояние от оси. Отбрасывается всё вне
`−2r ≤ z ≤ 3r`, `r ≤ 1.02 r_exit`. Светятся:

- «шип» (центральное тело) — `z < 0.2 r`, `r < 0.75 r`: `T = Tair + dT`;
- внутренняя стенка колокола — `z ≥ −0.1 r` и нормаль смотрит к оси (`facing < −0.15`):
  `T = Tair + dT · lerp(0.8, 1, sat(z/2r))`.

Яркость: `L = kE · Emissivity · B_rel(T) · ExAirTrans(sd)`, аддитивно. Ветка для узла без сопла в шейдере есть
(`:45-50`), но CPU всегда передаёт `ax.w = 1`, поэтому она не выполняется.

## 8. Тепловое марево

Работает только при `Shimmer = 1`, `sc.dense` и `Tg > 10 K` (газ у фокуса). Источники: столбы от горячих узлов и
струй (`exhaust_shimmer.hlsl`) плюс поле температуры 3D-потока (`smoke.hlsl: PSShimmer`).

### 8.1. Модель

Горячий газ при том же давлении менее плотен: `δn = K · ρa · dT/(Ta + dT)`, `K = (n − 1)/ρ = 2.3e-4` м³/кг для N2,
воздуха, CO2 (`K_REFR`, `Exhaust.cpp:19`). Вихри размером ~0.3 ширины горячей области отклоняют луч на
`~δn · sqrt(L/l) ≈ 5 δn` рад. На экране фон смещается на этот угол × фокусное расстояние в пикселях
× `(1 − d_газа/d_фона)`.

### 8.2. Столбы (`DrawShimmer`, `Exhaust.cpp:535-609`)

Амплитуда `amp = 5 · K_REFR · ρa · dT/(Ta + dT)` [рад]; столб пропускается при `amp < 2e-6` или если середина дальше
`3000 м + длина`. До 32 столбов.

| Источник | Отрезок | Полуширина | Скорость вихрей [м/с] |
|---|---|---|---|
| горячий узел (`kind 1`) | от `g − 0.5r·up` до `g + 4r·up` (вертикаль фокуса) | 1.3r → 1.6r | `min(3, sqrt(g_тела · r · dT / Ta))` |
| струя (`kind 0`), `dT = T − Ta ≥ 20`, `vacW ≤ 0.9` | от `eg` на `L = clamp(Lc · dT/(0.1 Ta), 20 re, 15)` по `dg` | 1.2 re → re + 0.11 L | `min(0.5 ve, 300)` |
| водородная струя | `L = clamp(Lc / cHot, 20 re, 15)`, `cHot` — первая доля в таблице, где `T_mix − Ta > 0.1 Ta` | то же | `min(0.6 ve Lc/(0.5 L), 0.35 · fps · 0.3 · 0.5 · w)` — не быстрее, чем кадры успевают показать |

Водородная струя не даёт столба, если 3D-поток работает (`SmokeLive()`): её марево — из поля потока (§9.5).

### 8.3. Проходы

1. `gc->CopySceneColour(copyTex)` — копия HDR-сцены (при MSAA — резолв, глубина резолвится заодно); `t5`, `t6`
   привязываются заново.
2. `offRTV` (R16G16_FLOAT, размер сцены) очищается; `VSProxy/PSProxy`, `DrawInstanced(6, n)`, аддитивно:
   каждый столб — квадрат вдоль оси, развёрнутый к камере.
   `PSProxy` (`exhaust_shimmer.hlsl:44-65`): маска `across = (1 − (2u−1)²)²`, вдоль — нарастание и спад (у струи
   от среза, у узла — подъём столба); отбрасывается, если сцена ближе газа; `k = 1 − d_газа/d_сцены`;
   два value-noise с масштабом `1/(0.3 w)`, сносимых со скоростью столба; `offPx = noise · amp · mask · focal · k`,
   `focal = P._22 · 0.5 · H` (`sMisc.x`). Пишется смещение в долях экрана.
3. `SmokeShimmer(gc)` — 3D-поток добавляет свои смещения в ту же цель (§9.5).
4. RTV сцены, `bsOpaque`, `t3` = смещения, `t4` = копия; полноэкранный треугольник `VSFull/PSComposite`
   (`:70-82`): при смещении меньше ~0.03 пикселя пиксель отбрасывается, иначе берётся копия по `uv + off`.

Марево применяется до факелов и частиц, поэтому сами факелы им не искажаются.

## 9. Дым и конденсат как 3D-поток

`Smoke.cpp`, `smoke.hlsl`. Один решатель для всех двигателей вокруг фокуса; источники — `SmokeSrc`, которые
заполняет `H2Jet` (§6.5). На дату состояния источники порождает только водородная ветка (струи «Модуля полёта» и
универсальные струи); поле `mVis` предусмотрено и для сажи («later soot», `ExhaustInternal.h:104`), но не заполняется.

### 9.1. Источник (`Exhaust.cpp:456-472`)

| Поле `SmokeSrc` | Значение |
|---|---|
| `eg`, `dg`, `rExit`, `h`, `id` | срез, направление, радиус, корабль, id струи |
| `kJ` | `sqrt(F / max(ρa, 1e-4))` [м²/с] — кинематический импульс свободной струи |
| `mVis` | `vis ? fc · W · ṁ : 0` [кг/с] |
| `zFull` | `zStar` [м] — масса формируется на `0..zFull` с долей `(z/zFull)²` |
| `inject` | `clamp(7 kJ/30, 0.3, min(max(3, 10 re), zHit))` — длина, на которой навязывается поток струи (до скорости ~30 м/с или до земли) |
| `Tex` | `max(0, tMix[i] − Ta)` при `u` из `c_ax = min(1, Lc/inject)` — избыточная температура смеси (плавучесть, марево) |
| `decay` | `life > 30 ? 0 : 1/life` [1/с] — испарение видимой массы (на Титане 0) |

Корабль источника заносится в `g_exModelled`: его потоки частиц `AddExhaustStream` в этом кадре скрываются (§12).

### 9.2. Сетка (`SmokeFx::Update`, `Smoke.cpp:126-226`)

- Работает только при `sc.anchored` (локальная система частиц задана, см. §10.1) и `sc.dense`. Если источников нет
  дольше 90 с — коробка снимается.
- Сетка `NX × NY × NZ = 128 × 64 × 128` ячеек, ось `y` — вверх (локальная система частиц).
- Размер ячейки `h = clamp(max(SmokeCell, 6 · size_фокуса / 128), SmokeCell, 2)` [м] (скафандр — 0.2 м, коробка
  25.6 × 12.8 × 25.6 м; DG — около 0.5 м). При смене `h` коробка сбрасывается.
- Коробка стоит на месте; сдвигается целыми ячейками (поле переносится), когда фокус подходит ближе четверти размера
  к краю по `x/z`, или выходит из полосы по `y`; пол — на `3h` ниже грунта (или уровня жидкости). При сдвиге на
  половину размера и более или при смене якоря поле очищается.
- `dt = min(simDt, 1/30)`; на паузе (`dt = 0`) решатель не шагает, освещение и занятость пересчитываются.
- Источники: 8 сильнейших по `kJ`; для каждого — срез кадр назад (`lastExit`), масса раскладывается вдоль пути
  среза за кадр, `K = clamp(ceil(|Δ| / 0.5h), 1, 16)` подпозиций.
- Константы: `kDt = (dt, SmokeConfine, 0.7, decay)` — релаксация температуры 0.7 1/с; `decay` берётся у последнего
  источника в списке и действует на всю коробку; `kSun.w = 1700` м²/кг — экстинкция льда с r ≈ 1 мкм (Schumann 1996);
  оседание Стокса `ws = 2/9 · (917 − ρa) g r² / μ`, `r = 1e-6` м; `kPhys.z = 2.3e-4 · ρa` — `n − 1` воздуха.

### 9.3. Шаг решателя (Stam 1999, «Stable Fluids»)

Последовательность диспатчей (`Smoke.cpp:209-223`), группы 8×8×8:

| Шаг | Шейдер | Что делает |
|---|---|---|
| адвекция | `CSAdvect` (`smoke.hlsl:50`) | полулагранжев перенос RK2 скорости (`xyz`), избыточной температуры (`w`) и массы с учётом сдвига коробки; обратный след не уходит под грунт; масса дополнительно оседает со скоростью `ws`; извне коробки — неподвижный чистый газ |
| завихренность | `CSCurl` (`:74`) | `ω = ∇ × v`, `|ω|` |
| силы и источники | `CSForces` (`:90`) | vorticity confinement `f = ε h (N × ω)`, `N = ∇|ω|/|∇|ω||` (Fedkiw, Stam & Jensen 2001); плавучесть Буссинеска `Δv_y = dt · g · T'/(Ta + T')`; вес переносимой массы `Δv_y = −dt · g · ρ_m/ρa`; `T' *= exp(−0.7 dt)`; источники (ниже); `ρ_m *= exp(−dt · decay)` |
| дивергенция | `CSDiv` (`:166`) | грунт — твёрдая стенка (отражение `v_y`), боковые грани открыты |
| давление | `CSJacobi` (`:189`) × `SmokeIters` | Якоби; вне коробки `p = 0`, в грунте — градиента нет |
| проекция | `CSProject` (`:201`) | `v −= ∇p`, затем копия `vel[0] → vel[1]` |
| свет | `CSLight` (`:218`) | на половинном разрешении: пропускание к Солнцу (32 шага) и вверх (24 шага) по массе с `k = 1700` |
| занятость | `CSOcc` (`:245`) | блоки 8³ (с запасом в ячейку): максимум массы и `T'` — марш пропускает пустые блоки |

Источник в `CSForces` (`smoke.hlsl:114-158`):

```
масса:   z ∈ [0, inject],  bw = 0.094 · max(z, 2h) + re,  σ = max(0.6 bw, 0.6 h)
         dF = 2z/zf² при z < zf;  если zf > inject — остаток (1 − (inject/zf)²) кладётся в последние 3 ячейки
         ρ_m += dt · mVis · dF · gauss(r, σ) / K           (по K подпозициям вдоль пути среза)
поток:   bw = 0.094 · max(z, 2h) + re   (радиус половинной скорости)
         wv = exp(−0.693 r²/bw²) · sat(1 − (z − inject)/h)
         uz = min(7 kJ / zc, 5.4 h/dt)                       осевая скорость свободной круглой струи
         цель = (ось + колебание ±(0.06 + 0.04) рад на 2.7–5.3 Гц) · uz
         v = lerp(v, цель, sat(0.6 wv)),   T' = max(T', Tex · wv)
```

### 9.4. Рисование (`VSDraw`/`PSDraw`, `smoke.hlsl:279-341`)

Коробка (36 вершин) в глобальной системе; марш с шагом `0.5h` (до 700 шагов), пустые блоки 8³ перескакиваются
(`NextT`). Масса → `σ = ρ_m · 1700`, `a = 1 − exp(−σ ds)`. Освещение: Солнце (`SunLight` FX-атмосферы в центре
коробки) через собственную тень облака (`tLightR.x`), фаза Хеньи — Гринстейна g = 0.75, с утолщением — к
изотропному; небо сверху (`SkyLight(up)` × `tLightR.y`) и земля снизу; альбедо 0.97 (лёд).
Выход premultiplied: `(L · ExAirTrans(ta), 1 − T_acc)`; при `T_acc > 0.998` пиксель отбрасывается.

### 9.5. Марево из поля температуры (`PSShimmer`, `smoke.hlsl:356-395`)

`n' = −kPhys.z · T'/(Ta + T')`; угол `α = ∫ ∇⊥n' ds` (центральные разности по ячейке, шаг `0.5h`, только
занятые блоки по `T' > 0.5`); перевод в смещение экрана — разность проекций точек в 10 м по лучу и по
отклонённому лучу. Результат добавляется в `offRTV` вместе со столбами §8. Множитель `(1 − d_газа/d_фона)`, который
есть в `PSProxy`, здесь не применяется; марш лишь обрезается глубиной сцены.

## 10. GPU-частицы: выброс грунта под струёй и конденсат

Подробности системы частиц (пул, источники `AtmoFX_Emit`, брызги) выходят за тему главы; ниже — то, что касается
струй.

### 10.1. Локальная система и пул

- `AnchorAt` (`GpuParticles.cpp:213-229`): точка на средней сфере под фокусом, оси `a1`, `aU` (вверх), `a2`,
  неподвижные относительно планеты. Переустанавливается при смене тела или удалении фокуса более чем на 3000 м
  (частицы старой системы сбрасываются). Устанавливает `sc.anchored`, от которого зависит 3D-поток (§9.2).
- Пул 65 536 частиц по 96 байт (`GPart` / `struct Part`), список мёртвых (consume/append), список живых (append),
  рисование `DrawInstancedIndirect` по 6 вершин. Новорождённые (до 4096 за кадр) собираются на CPU и заливаются в
  `newBuf`; `CSInit` → `CSEmit` → `CSSim`. Число живых читается со staging-буфера с отставанием 3 кадра.

### 10.2. Выброс грунта под струёй (`SpawnJet`, `GpuParticles.cpp:231-345`)

| Шаг | Формула / условие |
|---|---|
| отбор | `cosd = −dg · up ≥ 0.25`; высота среза `hExit ≥ −0.05` м над грунтом или жидкостью (затем `≥ 0.02`) |
| пятно | `t = hExit / cosd`, `θ = 12°` в плотном газе, 30° в вакууме; `r = re + t · tan θ` |
| давление торможения | `q = F · cosd / (π r²)` [Па] |
| скорость пристеночной струи | `uw = dense ? min(0.5 · sqrt(q/ρg), 80) : 0`; в плотном газе пятно (`hit`, `uw`, `r`) передаётся в `sImp[]` (до 8 пятен) для поля газа частиц |
| над жидкостью | `return` — выброса нет (код брызг и тумана ниже `return` недостижим) |
| порог сдвига (Shao & Lu 2000) | `ρp` = 920 (лёд) / 1200 (Титан) / 2650 кг/м³; `γc = 3e-4 (1 + 20 wet)`; `τc = 0.0123 (ρp g d_ref + γc/d_ref)`, `d_ref = 1e-4` м |
| условие | `0.06 q / τc > 1` |
| эрозия (закон типа Roberts / Metzger) | `ṁ = min(0.02 (0.06 q − τc) π r² / uE, 2)` [кг/с], `uE = dense ? max(uw, 1) : 50` |
| смеси классов | по классу грунта: `DRY_C`, `WET_C`, `REG_C`, `ICE_C`, `LIQ_C` (`GpuParticles.cpp:22-26`); у кромки жидкости (до 0.3 м над уровнем) грунт мокрый |
| частота спрайтов | `rate = clamp(kc / (0.25 · 6e-3), 8, 480)` 1/с на класс |
| скорость | плотный газ: радиально `uw · U(0.3, 1)`, вверх `uw · U(0.05, 0.35)`, плюс наклон струи; вакуум: баллистически `clamp(8 sqrt(q), 20, 600) · U(0.3, 1) · (1e-4/d)^0.3`, угол 1–6° |
| непрозрачность | `τ = 1.5 m / (ρp d) / (2 s0²)`, `a0 = min(0.9, 1 − e^(−τ))` |

В полёте (`CSSim`, `particles_gpu.hlsl:183-275`): гравитация с плавучестью, в плотном газе — сопротивление
Шиллера — Наумана к скорости газа `GasVelocity` (пристеночные струи от пятен `sImp`, свободные струи `sFree`,
вихри), в вакууме — только гравитация.

### 10.3. Конденсат как частицы (`Smoke = 0`)

`H2Jet` (`Exhaust.cpp:474-477`) регистрирует источник `parts.Emit(h, 9500 + 8·id, eL, 300·dL, cone = min(zStar, zHit),
0, kgps = fc·W·ṁ, kind = 4, ..., life, jetJ = F)`; при остановке струи источник снимается (`Exhaust.cpp:362-363`).
`SpawnSource`, вид 4 (`GpuParticles.cpp:419-442`): 300 · `capK` гауссовых «облачков» в секунду, положение
`z = z* · sqrt(U(0.0025, 1))` (плотность `2z/z*²`), σ = `0.1 z + 0.02` м, скорость
`v_земли + ось · min(7 kJ/z, max(|vel|, 5))`, сечение экстинкции `X = m · 2 · 1.5 / (917 · 2e-6)` [м²] в `ug0.x`,
флаг `F_COND`. В `CSSim` σ растёт: `dσ/dt = 0.1 |u_газа| · sat(1 − age/0.3) + (dense ? 0.05 : 0.005)/max(σ, 0.02)`,
не более 3 м. В VS: размер `2.5σ`, оптическая толщина в центре `X/(2πσ²)`; в PS (вид 9) `a = 1 − exp(−τ e^(−r²/2σ²))`,
наложенные облачка перемножают пропускания.

## 11. Собственные факелы кораблей (`VesselExhaust.cpp`)

Рисует все `AddExhaust` всех визуалов (`gc->Visuals()`), в проходе струй после частиц и 3D-потока.

CPU (`RenderVesselExhausts`, `VesselExhaust.cpp:41-101`):

- пропуск, если нет `lpos`/`ldir`, `lsize ≤ 0` или `wsize ≤ 0`;
- пропуск факелов с флагом `0x100` («Модуль полёта»), если `H2Flame = 1`: их рисует факел AtmoFX по химии;
- `level = GetExhaustLevel(i)`; при `modulate > 0`: `level *= (1 − modulate) + rand · modulate` (каждый кадр);
  пропуск при `level ≤ 0.005`;
- текстура — `es.tex` (как `Surf`) или `Textures\Exhaust.dds`; без текстуры факел не рисуется;
- система факела: `e = −ldir/|ldir|` (вниз по струе), начало `o = lpos − ldir · lofs`; матрица «система факела →
  сдвинутая глобальная» и `wvp`; камера в системе факела;
- `Draw(32 · 12)` — цилиндр из 32 сегментов с торцами; текстура в `t6`. Отсечения по расстоянию и по пирамиде
  видимости нет.

PS (`exhaust_vessel.hlsl:41-86`): пересечение луча с цилиндром `x² + y² ≤ R²`, `0 ≤ z ≤ L` (`R = wsize`,
`L = lsize`); рисует только дальняя грань; марш 32 шагами до `min(выход, глубина сцены)`; выборка
`u = 0.01 + 0.23 · (0.5 + 0.5 · r/R)`, `v = z/L` (раскладка стандартной ленты Orbiter: поперёк 0.01…0.24);
`sum += α_tex · dt`, цвет — средневзвешенный по `α_tex`. `alpha = (1 − exp(−sum / (0.9 R))) · level`;
излучение `em = цвет · eK.x / max(gAdapt.w · gAdapt.rgb, 1e-4)` — яркость на экране не зависит от адаптации глаза
(`eK.x = 1`, «как в D3D9»). Выход premultiplied.

## 12. Потоки частиц Orbiter (`Particles.cpp`)

Касается струй в двух местах:

- `clbkCreateExhaustStream` (`Client.cpp:669-681`) помечает поток `engine = true`. В `UpdateRenderParticles`
  (`Particles.cpp:158`) такой поток не рисуется, если его корабль в `g_exModelled` (выхлоп несёт 3D-поток).
- `PStream::Update` (`Particles.cpp:98-116`): у потока, уровень которого совпадает с уровнем факела
  (`es.level == level`), частицы рождаются в конце факела (`exit + e · lsize`), поочерёдно по факелам (до 16), и
  проявляются за `tIn = max(10, 2 lsize) / v0` (`Particles.cpp:163`) — имитация конденсации на длине смешения.
  Поток без связанного факела рождает частицы в своей точке.

Полное описание `PStream` — в [architecture.md](architecture.md) и [orbiter-api.md](orbiter-api.md).

## 16. Ограничения, известные проблемы, расширение

### 16.1. Ограничения модели

- `γ = 1.3` для всех струй; газовая постоянная выводится только из `ve` и `Te` в предположении торможения при
  `~2 Te`. Состав выхлопа — только H2 + H2O (`yH2`); для `Rs ≤ 450` струя считается «тяжёлой» и описывается одним
  `Kabs` без химии.
- Дисков Маха и отражённых скачков нет; ударные ячейки — периодический нагрев на оси с затуханием `exp(−z/0.8Lc)`.
  Нерасчётность учитывается только через `rj` и амплитуду `shock` при `n` от 0.2 до 30.
- Переход вакуум — атмосфера — линейное смешение двух полей по `vacW` (логарифм `n` от 1.5 до 3).
- Факел, марево и поток используют газ **у фокуса** (`Ta`, `pa`, `ρa` в `DrawPlumes` и `DrawShimmer`), а `JetGas` —
  газ у корабля струи: для струи другого корабля на другой высоте величины смешаны.
- Струя не взаимодействует с грунтом геометрически: факел AtmoFX проходит сквозь землю до глубины сцены; растекание
  по поверхности есть только в GPU-частицах (пристеночная струя `sImp`) и в 3D-потоке (твёрдое дно).
- Свечение сопла и марево узлов не учитывают ориентацию сопла относительно вертикали — столб марева узла всегда
  по вертикали фокуса.
- Сажа (`mVis` для углеводородного выхлопа) в 3D-поток не подаётся; источники 3D-потока порождает только водородная
  ветка.
- Нет выброса грунта и брызг над жидкостью (`SpawnJet`: `return` при `liquid`, `GpuParticles.cpp:262`; ниже
  недостижимый код) и при сопле под поверхностью жидкости (комментарий «the foam is not done», `:243`).
- 3D-поток ограничен коробкой вокруг фокуса (до ~256 м при ячейке 2 м) и восемью сильнейшими источниками; `decay`
  один на всю коробку (последнего источника, `Smoke.cpp:164`).
- Конденсация на телах кроме Земли считается при `ea = 0` (сухой газ); «Earth» и «Titan» определяются по имени тела.

### 16.3. Как расширять

**Новый тип топлива (например, керосин/O2 или метан/O2).**

1. Сейчас тип определяется косвенно: `Rs` из `ve`, `Te` (`JetGas`), затем `yH2` по правилу смешения H2/H2O
   (`Exhaust.cpp:357`). Для другого состава нужен явный признак: проще всего — поле в `ExJet` (и, при желании, новый
   экспорт AtmoFX или флаг в существующем), выставляемое в `Collect`.
2. Химия: в `H2Chem.cpp` добавить виды (CO, CO2, при необходимости C(s) как сажа) с NASA-7 коэффициентами в
   `NASA[][][]`, `MW[]`, строку элементов в `EL[][]` (расширить до 4 элементов H, O, N, C — массивы `b[3]`, `lam[3]`,
   `J[4][5]` и `act[3]` в `Equil` рассчитаны на 3 элемента), функцию элементов выхлопа вместо `ExhaustEl`.
   Стехиометрию `fs` в `Mix` (`7.937` — только для H2) заменить общей.
3. Оптика: для сажистого пламени излучение — Планк с поглощением (`κ = Kabs · ρ_сажи`, уже есть путь
   `ExBlackbodyRel`); для чистого пламени — свой спектр хемилюминесценции по образцу `Cont`/`ContinuumRGB`
   (CH*, C2* для углеводородов) и своё поле в `PlumeCB` вместо `pKc`.
4. Шейдер: ветку `pH2.x` в `Field` обобщить на «пламя по таблице» (таблица `pOH[8]` — уже 32 значения по `u`).
5. Конденсат/дым: заполнить `SmokeSrc::mVis` для сажи и `decay = 0` (сажа не испаряется); оптика 3D-потока сейчас
   рассчитана на лёд (`kSun.w = 1700`, альбедо 0.97) — для сажи нужны своя экстинкция и малое альбедо, т. е. второй
   канал массы или признак вещества.
6. Журнал: дополнить формат в `ExhaustFx::Log`.

**Новый эффект в проходе струй.** Добавить вызов между шагами §2.2 (после `DrawPlumes` — для premultiplied-проходов);
