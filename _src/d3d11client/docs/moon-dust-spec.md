# Лунная пыль из-под колёс — спецификация и приёмка (22.10.2026)

Владелец реализации: сессия «Луна: пыль под колёсами» (`src/Regolith.cpp`, `shaders/regolith.hlsl`, `src/GpuParticles.cpp`).
Приёмку по числам делает мастер D3D11 до того, как сборку увидит пользователь.

## 1. Что известно (источники)

| Факт | Источник | Как используем |
|---|---|---|
| В вакууме висящего облака нет; тяжесть 1/6 усиливает пыльность | Mullis, NASA CR-121075 (1971), выводы | после остановки пыль исчезает за время полёта, никакого «тумана» |
| Пыль за LRV летит по чистой баллистике, начальная скорость связана со скоростью ровера | Hsu & Horányi, Am. J. Phys. 80, 452 (2012), по кадрам Apollo 16 «Grand Prix» | только g = 1,62 м/с², без сопротивления, без разделения по размерам |
| Медиана частиц реголита ~70 мкм (40–130 по пробам); 10–20 % массы мельче 20 мкм | NASA 1974 (Apollo 11–15); обзоры по Carrier 2003 | распределение размеров ниже |

Чего нет в источниках (наши допущения, помечены **[Д]**): распределение углов отрыва грунта с обода и толщина
захватываемого слоя. Числа для них выводятся из кинематики, а не подбираются на глаз.

## 2. Физика (точная механика, без подгонки)

Колесо радиуса R = 0,8 м катится со скоростью v, скорость обода v_r = ω R (без проскальзывания v_r = v,
проскальзывание s: v_r = v / (1 − s); полное буксование v = 0).

Частица отрывается от обода в точке на угле α, отсчитанном от точки контакта назад-вверх (0° — контакт,
90° — на высоте оси сзади). Её скорость в системе грунта:

- вдоль хода: u_x = v − v_r cos α
- вверх: u_z = v_r sin α
- (поворот колеса δ — тот же вектор в плоскости колеса)

Без проскальзывания: u_x = v (1 − cos α), u_z = v sin α. Отсюда в системе машины грунт уходит назад со скоростью
v cos α — это и есть «хвост».

Дальше — только баллистика: z(t) = z0 + u_z t − g t²/2, g = 1,62 м/с², никакого сопротивления, никакой
зависимости от размера. Вершина: H = z0 + u_z²/(2g), время полёта t_f ≈ 2 u_z / g.

**Скорость отрыва:** только кинематика обода с фактической v_r (проскальзывание — от модуля машины). Вертикальная
составляющая ≤ v_r, поэтому граница вершины H_max ≤ v_r²/2g + R. Множители скорости сверх обода (k > 1) не вводятся:
скорость выше обода даёт только проскальзывание, и оно уже в v_r.

**[Д] Углы отрыва (по сессии пыли, со ссылкой на Hsu & Horányi 2012):** ~80 % массы на α 10–75°, ~20 % — грунт, который
протектор переносит через верх, на α 150–220° (летит вперёд-вниз). Выше крыла (α_max из `.dust`) — в крыло.

**Масса:** не задаётся клиентом. Её присылает модуль машины (TVChassis: ṁ = ρ_насып · W · δ · v_r, для Луны и Ио
δ = 0,1 мм, откалибровано там). Клиент массу не умножает и не подменяет: один источник правды.

**Размеры (по массе):** 15 % 5–20 мкм, 35 % 20–70 мкм, 35 % 70–250 мкм, 15 % 250 мкм–1 мм.
Все фракции летят по одной параболе: в вакууме сортировки нет.

**Оптика свободной частицы** (d ≫ λ, экстинкция Q = 2: половина — дифракция, половина — сама частица):
- дифракционная половина: узкий пик вперёд (HG g ≈ 0,9), без поглощения;
- вторая половина — частица по Хапке: альбедо однократного рассеяния w ≈ 0,28, обратное рассеяние HG g ≈ −0,3
  (частица реголита, Hapke). В слое реголита дифракцию не считают — частицы вплотную; в свободном полёте она есть.
- Итого фаза двухлепестковая, одинаковая для точек и поля. Однократное рассеяние Солнца, тень на грунт из того же
  объёма света. (Ранее здесь стояло альбедо 0,12–0,15 — это альбедо поверхности, не частицы; исправлено.)

## 3. Отрисовка (принятые решения пользователя)

- Частицы — точки размером 1 пиксель, без растущих дисков (пользователь: «идеально»).
- Поле — мелкая фракция (< 70 мкм: ~97 % экстинкции при ~50 % массы); крупная (≥ 70 мкм) — точки. Разделение
  по размеру, не по числу точек на пиксель: порог по пикселям зависит от камеры и мигает при наезде.
  Марш по схеме `smoke.hlsl` (`PSDraw`, `CSOcc`, `CSLight`), освещение через `common.hlsli` / `exhaust_common.hlsli`.
- Край хвоста резкий, парабола видна; никаких клубов, расплывания и «киселя».

## 4. Приёмка — числа, которые должен писать лог

Строка раз в 10 с: скорость машины v, скорость обода v_r, число живых частиц, доля оптической толщины в поле,
максимальная вершина H_max над грунтом, максимальный горизонтальный вылет, время жизни последней частицы после
остановки, стоимость GPU (точки, поле, свет).

| Проверка | v = 3 м/с, без проскальзывания | v = 8 м/с | Допуск |
|---|---|---|---|
| H_max (вершина над грунтом) | ≤ v_r²/2g + R; без проскальзывания 2,78 + 0,8 = 3,6 м | ≤ 19,8 + 0,8 = 20,6 м | не выше границы с фактической v_r из лога; не ниже 60 % от неё |
| вершина при α = 45° | 1,39 м | 9,9 м | ±15 % по частицам из этого угла |
| время полёта при α = 45° | 2,6 с | 7,0 с | ±10 % |
| падение после остановки | всё на грунте за ≤ 3,7 с + 0,5 с | ≤ 9,9 с + 0,5 с | никаких висящих частиц |
| ускорение частиц по вертикали | −1,62 м/с² | −1,62 м/с² | ±1 % (нет сопротивления) |
| сквозь колёса и корпус | < 1 % частиц | < 1 % | по SDF |
| стоимость GPU всего | ≤ 2,0 мс | ≤ 2,0 мс | 1080p, RTX 4050, 8 колёс |
| из неё поле | ≤ 1,0 мс | ≤ 1,0 мс | |

Полное буксование (v = 0, v_r = 3 м/с): u_x = −v_r cos α (грунт летит назад), H_max ≤ v_r²/2g + R.

## 4а. Принятый вид — эталон (пользователь, 22.10.2026)

Сборка 18:15 на ЭМПУ без форсажа принята: «вот БЕЗ форсажа КЛАССНО!». В ней: всплески k = 0,7–1,6·v_r
(**[Д]**: множитель над ободом, ссылка на Hsu & Horányi 2012, по первоисточнику не проверен), поле мелочи 0,2 м
в половинном разрешении, фаза HG(−0,3). Это эталон вида: правки не меняют его при обычной езде.
Исправляется только форсаж (большое проскальзывание): редкая мелочь, которая разлетается и в поле даёт «шары»,
остаётся точками. Граница вершины в приёмке для этого вида: H_max ≤ (1,6 v_r)²/2g + R.
Пункты 2–3 выше (k = 1, двухлепестковая фаза) — направление на потом, только если пользователь сравнит и выберет.

Оседание после остановки считается по зёрнам, не касавшимся корпуса (баллистика). Зёрна, упавшие на машину и
съехавшие с неё, — осыпание с корпуса, не полёт; их время в границу не входит (22.10: 8 м/с — 12–17 из ~145 тыс.,
на высоте крыши, вверх ≤ 0,85 м/с, до 21,8 с). Трение на корпусе ради числа не меняется: вид скольжения принят.

**Приёмка 22.10.2026:** 3 м/с — H_max 7,20 м (≤ 7,90), оседание 5,5 с (≤ 6,4), GPU ≤ 1,67 мс; 8 м/с — H_max 47,6 м
(≤ 51,3), баллистика осела в границу, GPU ≤ 1,97 мс. Принято мастером; вид — за пользователем.
