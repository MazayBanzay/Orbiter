что по коду выглядит как ошибка или расхождение с SDK, но вживую не проверялось.

## 3. API Orbiter

Не переопределены (работает поведение SDK): `clbkUpdate`, `clbkOptionChanged`, `clbkDebugString`, `clbkPreOpenPopup`,
`clbkSaveSurfaceToImage`, `clbkCopyBitmap`, `clbkCreateSurface(HBITMAP)`, `clbkGetDeviceColour`, `clbkSetMeshMaterialEx`,
`clbkMeshMaterialEx`, `clbkStoreMeshPersistent`, `clbkCreateAnnotation`, `clbkFilterElevation`, `RenderWndProc`.
Заглушки: `clbkSetMeshProperty`, `clbkBeginBltGroup`, `clbkEndBltGroup`. Подробно — [orbiter-api.md](orbiter-api.md).

gcCore: реализованы 8 методов из ~50; список недостающих — [extensions.md §2](extensions.md#2-gccore).

## 4. Проверить (возможные ошибки)

1. `clbkSetMeshTexture`: SDK говорит то «texidx ≥ 0» (`GraphicsAPI.h:548`), то «1..n» (`oapiSetTexture`); код
   считает индекс 1-based. Проверить на модуле, который меняет текстуры мешей.
2. `clbkGetMeshGroup` отдаёт в `TexIdx` наш слот (индекс + 1, 0 = нет), а не индекс Orbiter / `SPEC_DEFAULT`.
3. `clbkSetMeshMaterial`/`clbkMeshMaterial` при `NULL`-меше возвращают 2 («не поддерживается»), по SDK — 3.
4. gcCore `GetMatrix` игнорирует `MatrixId`; `GetMeshMaterial`/`GetSystemSpecs`/`GetSurfaceSpecs` возвращают 0 без
   заполнения выходных структур — вызывающий может принять это за успех.
5. `RENDERPROC_HUD_1ST` рисуется поверх HUD Orbiter, а не под ним.
6. AtmoFX: `SetJet` с `thrust = 0` и `SetWake` с нулями не удаляют записи; записи не чистятся при удалении корабля;
   устаревание струй (0.5 с) — на потребителе.
7. Частицы: у излучающих потоков альфа применяется дважды (`rgb·a²`, `particles.hlsl` + `bsAdd`).
8. `fx_atmo` читает `depthSRV`; при MSAA эта одновыборочная глубина обновляется только в `CopySceneColour`, которую
   вызывает проход жидкости. Если жидкости в кадре нет, эффект атмосферы может читать глубину прошлого кадра
   (⚠ код сглаживания и эффектов менялся во время написания — проверить в текущей версии).
9. Исчезнувший корабль: `VesselVis` удаляется без `UnregisterVisObject` (`ScanVessels`).
10. `Planet::tilesLoaded++` из потока загрузчика без атомарности (на работу не влияет).
11. `shim\shim.def` в сборке не участвует — либо подключить, либо удалить, чтобы не расходился с `shim.c`.
12. `cbGrp` создаётся и не используется.
13. Интервал `post` в строке статистики (11–16 мс при 60 fps) — выяснить, что в него попадает.
14. `tools\run_test.ps1` оставляет `Scenarios\Tests\D3D11_test.scn`.
