# Колеи и следы (проект, 2026-10-20)

Разбор того, как это делают: Batman Arkham Origins (GDC 2014), Rise of the Tomb Raider (GPU Pro 7, «Deferred Snow
Deformation»), Spintires/MudRunner (разбор разработчика на Gamasutra), Unreal (скользящий render target). Код не берём,
пишем своё.

## Физика
- Колесо (Беккер / Вонг): z = [3W / ((3−n)(k_c + b·k_φ)·√D)]^(2/(2n+1)); подошва: z = (p / (k_c/b + k_φ))^(1/n).
- Луна (Wong, проверить по первоисточнику): n = 1, k_c = 1.4 кН/м², k_φ = 820 кН/м³. Проверка: LRV (285 Н на колесо,
  b 0.23, D 0.82) → ~1.8 см (наблюдали 1–2 см); ботинок Apollo ~7 кПа → ~0.9 см.
- Вал: вытесненный объём V, в вал (1−κ)·V; κ уплотнения: реголит 0.5–0.7, снег 0.9, мокрая грязь 0–0.2.
  Гауссов вал у края (0.6–0.8·b от оси, σ ≈ 0.25·b).

## Дизайн
1. Тороидальное окно деформации у фокуса: 2048², R16G16F (R — сдвиг высоты, G — нарушенность/уплотнение), тексел 2 см
   (~41 м), снаппинг к текселу, координаты в двойной точности на CPU.
2. Штамп (compute): капсула от прошлой точки контакта до текущей; профиль: плоское дно b + вал; глубина по Беккеру от
   нагрузки (точки касания Orbiter) и грунта тела; запись min для впадины, max для вала вне колеи.
   Ступня — по касанию из анимации CrewMember (форма подошвы, yaw).
3. Грунт: нормаль из окна в PS (везде в окне), тесселяция со сдвигом в ~25 м (и в проходе теней); материал по G:
   реголит темнее и глаже, грязь темнее и влажнее, снег светлее.
4. Уходящие из окна полосы — в разреженный кэш тайлов 64×64 м (8 см/тексел) на CPU; затухание по среде (Луна — никогда).

Порядок: окно + нормаль/альбедо → тесселяция и тени → кэш → связь с физикой.
