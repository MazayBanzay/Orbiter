# Циклон Земли в D3D11: проект v2 (на согласование)

Заменяет v1 (`Storm.cpp`/`storm.hlsl`: рисунок урагана формулами). v1 остаётся рабочей до готовности v2.
Основа — три исследования (ссылки в конце): AAA-рендер облаков, GPU-симуляция, физика урагана по наблюдениям.

## 0. Что было не так в v1
- Ураган **нарисован**: спирали — косинусы, глаз — кольцо, щит — диск. Он не живёт, не развивается, выглядит как вырезка (диск с кратером).
- Освещение — короткий марш к Солнцу на каждом шаге: дорого и без теней между облаками.
- Нет SDF/пропуска пустоты, нет Beer Shadow Map, нет LUT многократного рассеяния, нет правильной экспозиции под облаками.

## 1. Архитектура v2 (три слоя)

```
 СИМУЛЯЦИЯ (compute, 2D, 512²)  →  ПОЛЯ ОБЛАКОВ (Nubis-формат)  →  РЕНДЕР (марш + свет + время)
 вихрь, влага, конденсация           покров/тип/низ/верх/наковальня      SDF-пропуск, Beer shadow map,
 глаз и полосы возникают сами        + 3D профиль стены глаза            октавы Wrenninge, 1 из 4 лучей
```

## 2. Симуляция урагана (новое, главное)

**Модель:** двухслойная влажная модель «мелкой воды» на вращающейся Земле (moist-convective rotating shallow water,
Lahaye & Zeitlin; Rostami & Zeitlin 2018). 3D-сетка не годится: область 2000×16 км (125:1), 3D-модели облаков
(Stormscapes/Thunderscapes) — для 20–30 км и 0.24–0.81 с/кадр на A6000.

Слой 1 — приток (0–3 км), слой 2 — отток (10–15 км). Для каждого слоя i: толщина `h_i`, скорость `u_i`.

| Уравнение | Смысл |
|---|---|
| `∂u_i/∂t + (u_i·∇)u_i + f ẑ×u_i = −∇Φ_i − C_D|u_1|u_1/H (слой 1) + ν∇²u_i + обмен импульсом` | движение, Кориолис, трение о море |
| `Φ_1 = g(h_1+h_2)`, `Φ_2 = Φ_1 + g′h_2` (`√(g′H)` ≈ 40–60 м/с) | давление слоёв |
| `∂h_1/∂t + ∇·(h_1u_1) = −γP`, `∂h_2/∂t + ∇·(h_2u_2) = +γP − (радиац. охлаждение)` | конвекция переносит массу вверх |
| `P = (Q − Q_s)/τ` при `Q > Q_s`, `τ` ≈ 0.5–2 ч, `Q_s(SST)` | конденсация (поток массы) |
| `∂Q/∂t + ∇·(Q u_1) = −P + E`, `E = C_k|u_1|(q*(SST) − Q)/H` | влага; испарение с тёплого моря (WISHE) раскручивает шторм |
| `∂W/∂t + ∇·(W u_2) = P − W/τ_rain` | вода в облаках |
| `∂A/∂t + ∇·(A u_2) = P − A/τ_anv`, `τ_anv` 6–12 ч | лёд наковальни → щит перистых и отток |

- Кориолис: f-плоскость, `f₀ = 2Ω sin φ` = 6.16·10⁻⁵ с⁻¹ (25° с.ш.); β-плоскость (`β` = 2.07·10⁻¹¹) даёт сама дрейф на северо-запад.
- Что получаем **без рисования**: кольцо завихренности стены глаза неустойчиво → многоугольный глаз и мезовихри
  (Schubert 1999); спиральные полосы = вихревые волны Россби (Montgomery & Kallenbach 1997; Guinn & Schubert 1993);
  антициклонический отток наверху; опускание в глазу.

**Численно:** сетка 512² на 2048 км (4 км/ячейка), Arakawa C; перенос MacCormack/BFECC с ограничителем (иначе спирали
размываются); Кориолис — точный поворот `(u,v)` на `−fΔt`; волны тяжести явно (forward-backward, Δt ≈ 30 с) или
полунеявно с решением уравнения Гельмгольца/Пуассона многосеточным V-циклом (Δt 120–300 с); губка 100 км по краю.

**Старт:** слабый вихрь (~15 м/с на 100 км) + 1 % шума; зрелый шторм — за 2–4 суток модельного времени (~10⁴ шагов ≈ 3 с
GPU при загрузке) или сохранённое состояние. **Цена:** шаг 0.15–0.35 мс; при ×100 ускорения — < 0.1 мс/кадр в среднем.

**Проверка по наблюдениям (цели):** Rmax 30–45 км; глаз ~20 км у поверхности → ~35 км на 12 км; стена 15–25 км, наклон
~45° внизу, круче вверху; верхи 15–16 км (пробивающие — 17); щит: низ ~8 км, радиус 300–400 км; главная полоса на 3–5 Rmax;
ширина полос 5–50 км, длина 100–300 км; оборот на Rmax ~79 мин; смещение ~20 км/ч на северо-запад.

## 3. Из полей симуляции — поля облаков (формат Nubis «superstorm/envelope»)

2D-текстуры 512² (сим) → апскейл 2048² с переносом мелочи: **покров, тип (St→Cb), высота низа, высота верха, наковальня,
маска молний**.
- Конвекция (`P > 0`) → столб Cb: низ ~0.6 км, верх 12–16 км по `P`; в стене глаза — наклон наружу по поверхностям момента.
- `A` → щит перистых 8–15 км, толщина по `A`, линза к краю; волокна оттока — поток `u_2`.
- `Q ≈ Q_s`, `P = 0` → мелкие Cu/Sc 0.6–2 км. Глаз: опускание → ясно, Sc под инверсией 1.5–3 км.
- Стена глаза дополнительно — 3D-профиль 512×512×64 (Nubis Cubed) для свободных башен.
- Мелочь < 4 км — свой 3D-шум (128³ Perlin-Worley, 32³ Worley, 128² curl), переносится ветром слоёв (две фазы потока).
- Оптика: `σ = 3·LWC/(2ρ_w r_eff)` → ~0.05–0.1 м⁻¹ на г/м³ (видимость в стене 100–150 м).

## 4. Рендер (по проверенным схемам)

| Часть | Решение | Источник |
|---|---|---|
| Пропуск пустоты | луч ∩ оболочка/цилиндр шторма; затем грубое SDF шторма, шаг `max(sdf, k√dist) + jitter`; дешёвые/полные пробы | Nubis 2015, Nubis Cubed |
| Интеграция | энергосберегающая `(S − S e^{−σd})/σ` | Hillaire 2016 |
| Многократное рассеяние | 2–3 октавы Wrenninge (`a ≤ b`), фаза двухлепестковая HG; тёмные края — альбедо, не «powder» | Frostbite, UE, RDR2 |
| Свет Солнца | **сетка пропускания 256×256×32** по шторму, обновляется за 8 кадров; 1–2 живые пробы вблизи | Nubis Cubed |
| Тени облаков | **Beer Shadow Map** (R11G11B10: фронт, средняя экстинкция, макс. оптич. толщина) — для моря, суши, кораблей | Hillaire 2020 (UE) |
| Воздух | aerial perspective один раз на средней глубине облака; облака гасят воздух `L·T + L_cl` | Frostbite, Nubis |
| Время | половинное разрешение, **1 из 4 лучей** в блоке 2×2, AABB-клэмп 3×3 с учётом глубины, апскейл + TAA (1 из 16 — нет: медленно на орбите) | RDR2 |
| Внутри облака | два прохода по глубине: < 200 м — четверть разрешения без истории, дальше — половина | Nubis Cubed |
| Даль/орбита | тот же марш; шаги и октавы — по размеру пикселя; без переключения 2D↔3D | UE, Nubis 2022 |
| Точность | всё в локальной системе шторма относительно камеры, смещение — double на CPU; координаты шума по модулю тайла | — |
| Экспозиция | свет у камеры под облаками → адаптация глаза (крючок в FxAtmo, нужно согласие «Форка DX9») | — |
| Молнии | точечные источники из маски `P`; «внутреннее свечение» Nubis | Nubis 2022, RDR2 |

**Бюджет:** 1.5–2.5 мс при ~952×520 (ориентиры: HZD 1.2–2 мс PS4, Frostbite 1.6 мс XB1, RDR2 2.6 мс PS4, HFW 2–3 мс PS5).

## 5. Пролёт (физика)
Турбулентность из полей симуляции: `σ_w` ≈ 3 м/с в стене (TKE > 15 м²/с²), редкие удары 20–30 м/с; восходящие 4–8 м/с (до 20+);
в полосах вторичный максимум; в глазу спокойно; ветер слоёв — реальная скорость среды (сила сопротивления от относительного
ветра). Освещённость под стеной — единицы-десятки люкс.

## 6. Этапы (каждый — сборка + прогон + твои скрины)
1. Симуляция 512² отдельно + отладочный вывод полей (видно ли глаз, полосы, отток) — **сначала только она**.
2. Поля облаков из симуляции → текущий марш v1 (быстрая проверка вида с орбиты).
3. Рендер v2: SDF-пропуск, сетка света, Beer Shadow Map, октавы, 1 из 4.
4. Внутри облака: два прохода, экспозиция, молнии.
5. Физика пролёта из полей симуляции.
